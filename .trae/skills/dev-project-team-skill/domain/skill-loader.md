# SkillLoaderSkill — 任务级按需加载规则

> 版本：v1.0 | 日期：2026-08-28
> 所属：dev-project-team-skill 编排器
> 触发：交接文档 L1 核心摘要中"当前任务类型"字段

---

## 1. 设计目标

将编排器从"阶段渐进加载"细化为 **"任务级按需加载"**，解决长任务累计上下文触发频繁压缩的根因：

| 现状 | 目标 |
|------|------|
| 阶段级加载（整个阶段所有角色包） | 任务级加载（仅当前任务所需角色包） |
| 单阶段累计 5-10 个角色包 | 单任务仅加载 1-3 个角色包 |
| 上下文峰值 = 阶段累计未压缩包 | 上下文峰值 = 单任务所需包 |

---

## 3. 自动路由规则

### 3.1 路由来源优先级

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | **交接文档 L1 核心摘要** `当前任务类型` 字段 | 固化时自动生成，最高优先级 |
| 2 | 用户显式指令 | "启用需求分析师" 等显式触发 |
| 3 | 阶段上下文推断 | 基于当前阶段推断默认任务类型 |

### 3.2 路由算法

```python
def resolve_skill_packages(handoff_l1: dict, user_instruction: str = "") -> list[str]:
    """
    解析需加载的角色包列表
    返回：按加载顺序的角色包目录名列表
    """
    # 1. 从 L1 获取任务类型
    task_type = handoff_l1.get("当前任务类型", "")
    
    # 2. 若 L1 无，尝试从用户指令推断
    if not task_type:
        task_type = infer_from_instruction(user_instruction)
    
    # 3. 映射到角色包
    packages = TASK_TYPE_TO_PACKAGES.get(task_type, [])
    
    # 4. 总控包始终加载（只读模式可选）
    if "role-governance" not in packages:
        packages.append("role-governance")
    
    return packages
```

## 4. 加载模式扩展（token_standard.md §1.2 扩展）

| 模式 | 触发 | 加载行为 |
|------|------|----------|
| **任务级按需加载**（新增） | L1 有任务类型 / 用户指定任务 | 仅加载映射表对应的角色包（1-3个） |
| 阶段渐进加载 | 全生命周期 / 无任务类型 | 原有行为：按阶段渐进加载 |
| 角色组合加载 | 显式指定角色 | 用户显式指定的组合 |
| 敏捷迭代 | 敏捷/迭代/快速上线 | 迭代内冻结范围，按任务加载 |

## 5. L1 核心摘要扩展字段

交接文档 L1 核心摘要新增字段：

```markdown
### 当前任务类型
- **任务类型**：架构设计
- **任务边界**：ADR-003 数据架构设计，不含接口详细设计
- **输入依赖**：需求基线 REQ-001~015、架构策略 ADR-001/002
- **输出预期**：数据架构 ADR-003、数据模型、接口契约草案
```

字段定义：
| 字段 | 说明 | 示例 |
|------|------|------|
| 任务类型 | 映射表键名 | 架构设计 |
| 任务边界 | 本任务包含/不包含范围 | ADR-003 数据架构，不含接口详细设计 |
| 输入依赖 | 上游产出物引用 | REQ-001~015、ADR-001/002 |
| 输出预期 | 本任务交付物 | 数据架构 ADR-003、数据模型 |

## 7. 兼容性与回退

- **完全向后兼容**：无 L1 任务类型字段时，自动回退到阶段渐进加载
- **显式覆盖**：用户显式指定"启用需求分析师+测试工程师"优先于自动路由
- **总控包始终可用**：`role-governance` 作为横向支撑始终可选加载
