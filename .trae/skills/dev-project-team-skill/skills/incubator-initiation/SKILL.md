# incubator-initiation — 孵化器立项阶段技能

> **定位**：支撑新独立项目/技能/工具的立项评估（方案调研 + 可行性分析 + 风险初判），替代原 role-project-init 的通用启动流程。
> **职责边界**：只产出立项建议书（含可行性矩阵/风险雷达图/ROI估算），不代落地；落地交对应独立项目运营者。
> **触发词**：`立项评估`、`方案调研`、`可行性分析`、`孵化器启动`
> **Load when**：用户提出新项目/技能/工具孵化需求，且需跨模型/跨会话协同评估时。
> **技能版本**：v1.0.0

---

## 一、能力说明

- **方案调研**：自动检索同类项目（dev-git-hub 等先例）、行业标准（PMBOK/ISO）、技术选型（松耦合/薄封装/单一信源）
- **可行性分析**：五维评估（技术/资源/时间/成本/风险），输出可行性矩阵（高/中/低）
- **风险初判**：识别依赖项（如 SSH 授权/M2）、外部阻塞（远端仓库创建）、成熟度缺口
- **交付物**：立项建议书（Markdown + CSV 表格）+ 评审产物（证据卡 + 多视角评审报告）

## 二、使用方式

```bash
skill load incubator-initiation  # 加载技能
# 后续指令将自动启用该技能上下文
```

## 闭环执行系统

### 1. 任务入口
- 输入：用户提出新项目/技能/工具孵化需求（`立项评估`/`方案调研`/`可行性分析`/`孵化器启动`）；
- 前置：已明确孵化目标与约束条件；
- 不适用：已有独立项目的日常维护（由对应项目自身流程承载）。

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|----------|
| 待启动 | 用户触发立项评估 | 确认评估范围 | 确定孵化类型（项目/技能/工具）与评估维度 |
| 执行中 | 评估范围确认 | 建议书生成 | 方案调研 + 五维可行性分析 + 风险初判 |
| 校验中 | 建议书生成 | 门禁通过 | 校验可行性矩阵与风险雷达图完整性 |
| 完成 | 门禁通过 | 进入交接 | 更新交接断点与项目注册表 |
| 回退 | 评估数据不足 | 回到稳定版本 | 补充数据后重新评估 |

### 3. 执行动作层
- 执行步骤 1：方案调研（检索同类项目/行业标准/技术选型）；
- 执行步骤 2：五维可行性分析（技术/资源/时间/成本/风险），输出可行性矩阵；
- 执行步骤 3：风险初判与立项建议书编写（含风险雷达图/ROI估算）；
- 所需工具/脚本：`tools/mpv_cli.py`（多视角评审）；
- 输入输出约束：输入为孵化需求描述，输出为立项建议书（Markdown + CSV）。

### 4. 验收门禁
- 必须产出物：立项建议书（含可行性矩阵/风险雷达图/ROI估算）；
- 门禁条件：五维评估全部填写、风险识别完整；
- 未通过处理：补充缺失维度后重新提交评审。

### 5. 失败处理
- 异常类型：评估数据不足/外部依赖未就绪；
- 恢复策略：登记待确认项，建议用户补充后重新触发评估；
- 回退方式：保留上次有效评估结果。

### 6. 产出与交接
- 产出物：立项建议书（Markdown + CSV 可行性矩阵 + 风险雷达图）；
- 交接内容：当前评估状态、未关闭立项请求、关联文档索引。

### 7. 审计记录
- 操作人：AI Agent
- 操作时间：ISO8601 格式
- 操作内容：立项评估/可行性分析/风险初判
- 审计日志：操作留痕记录于 `13_安全审计台账.csv`。
