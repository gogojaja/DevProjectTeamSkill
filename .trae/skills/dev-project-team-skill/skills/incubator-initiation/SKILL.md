# incubator-initiation — 孵化器立项阶段技能

> **定位**：支撑新独立项目/技能/工具的立项评估（方案调研 + 可行性分析 + 风险初判），替代原 role-project-init 的通用启动流程。
> **职责边界**：只产出立项建议书（含可行性矩阵/风险雷达图/ROI估算），不代落地；落地交对应独立项目运营者。
> **触发词**：`立项评估`、`方案调研`、`可行性分析`、`孵化器启动`
> **Load when**：用户提出新项目/技能/工具孵化需求，且需跨模型/跨会话协同评估时。
> **技能版本**：v1.0.0

---

## 一、能力说明

- **方案调研**：自动检索同类项目（dev-git-hub 等先例）、行业标准（PMBOK/ISO）、技术选型（松耦合/薄封装/单一信源）
- **可行性分析**：五维评估（技术/资源/时间/成本/风险），输出可行性矩阵（高/中/低）
- **风险初判**：识别依赖项（如 SSH 授权/M2）、外部阻塞（远端仓库创建）、成熟度缺口
- **交付物**：立项建议书（Markdown + CSV 表格）+ 评审产物（证据卡 + 多视角评审报告）

## 二、使用方式

```bash
skill load incubator-initiation  # 加载技能
# 后续指令将自动启用该技能上下文
```
