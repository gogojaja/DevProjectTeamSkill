# Handover List 移交清单（建议书落盘 + 登记 + 脱敏）

> 归属：`../SKILL.md` §2.2.4　版本：v1.1.0

## 1. 目的

孵化决策为「移交独立项目」或「继续孵化」时，将评估产物固化为立项建议书（`docs/incubator/INC-*.md`）并完成登记闭环。**只产出建议书与登记，不代落地**——落地（建仓/编码/部署）交对应独立项目运营者。

## 2. 建议书六段模板（对齐存量范式 `docs/incubator/INC-*.md`）

```markdown
# 立项建议书：<对象名>
> **孵化器编号**：INC-<YYYY-MM-DD>-<NNN>（按序递增）
> **决策对象**：<独立项目/技能/工具>
> **档位**：LIGHT / FULL
> **评审模式**：多视角自评（非真实第三方）＋真实外部信号（<信号>）
> **评审结果**：🟢/🟡/🔴 <三态>
---
## 一、方案调研（复用 solution-research.md 产物）
## 二、可行性评估（五维矩阵 + 独立性判定，复用 feasibility-analysis.md 产物）
## 三、方案双栏（✅ 可稳定达成 / ⚠️ 限制，带证据引用）
## 四、评审报告（3 视角 + 聚合决策）
## 五、决策记录草案（ADR-xxx 占位 + 反信号）
## 六、移交清单（方案文档/评估依据/关联技能/登记路径）
```

**编号规则**：`INC-<日期>-<当日序号>`；放弃/复评类归档用 `EVAL-<日期>-<序号>`（先例：EVAL-2026-09-01-001）。

## 3. 登记闭环（移交独立项目必做）

| 登记项 | 位置 | 内容 |
|--------|------|------|
| 独立项目登记 | `references/project-registry.md` | 项目名/路径/授权号/单一信源声明 |
| AGENTS.md 登记 | 仓库根 `AGENTS.md` 独立关联项目区 | 薄封装代理调用说明（不内嵌实现） |
| 授权登记 | `台账/14_授权登记.csv`（`register_auth`） | 跨项目访问授权（铁律 #7a） |
| 审计留痕 | `台账/13_安全审计台账.csv`（`tools/audit.py`） | 立项评估操作四维留痕（铁律 #7 第 7 条） |
| 交接断点 | `交接文档.md` 待办区 | 移交状态与落地责任方 |

## 4. 移交前脱敏（强制）

建议书与证据卡落盘前跑 `tools/desensitize/desensitize.py --scan`（铁律 #8）：A 级真实凭据禁止入库；B 级主机名/IP/用户名/绝对路径脱敏后复查全文。扫描不过 → 禁止落盘。

## 5. 复评条件（继续孵化必写）

登记触发复评的量化条件（满足任一即重新评估），先例格式（EVAL-2026-09-01-001）：
1. ≥3 个外部项目产生实际复用需求（引用计数 >0）
2. 代码量/耦合度达到解耦阈值
3. 演进节奏与技能库发布节奏出现实质冲突

## 6. 产物

- `docs/incubator/INC-<日期>-<序号>_<对象名>.md`（立项建议书）
- 登记闭环五项（§3）全部完成
- 决策记录草案交 `role-architecture` 正式化

## 7. 门禁

- 六段任缺一段 → 禁止落盘
- 脱敏扫描未过 → 禁止落盘
- 登记闭环缺项（尤其授权登记与审计留痕）→ 移交视为未完成
- 落地动作（建仓/编码）出现在本技能执行范围内 → 越界驳回（职责边界铁律：只评估不落地）
