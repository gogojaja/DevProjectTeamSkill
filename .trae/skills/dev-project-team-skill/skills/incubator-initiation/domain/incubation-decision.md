# Incubation Decision 孵化决策（三选一 + 评审聚合）

> 归属：`../SKILL.md` §2.2.3　版本：v1.1.0

## 1. 目的

基于调研摘要与可行性矩阵，做出孵化决策（继续孵化/放弃/移交独立项目），经多视角评审聚合后输出决策记录草案。决策必须三选一，禁止模糊结论。

## 2. 决策三选一

| 决策 | 触发条件 | 后续动作 |
|------|----------|----------|
| **移交独立项目** | 五维可行性 ≥4 高 + 独立性判定满足（三判据 ≥2 或 8 维评分 ≥80） | 走 `handover-list.md` 移交清单 + 登记 |
| **继续孵化** | 可行性存疑（≥1 维低）或独立性不足（三判据 <2）但方向有价值 | 登记复评条件与观察期（先例：dev-deploy-tools 3 个月后复评） |
| **放弃** | 关键维度不可缓解（合规阻塞/无维护方/与既有资产完全重叠） | 记录放弃理由归档，防止重复立项 |

**判定优先级**：合规可行性低 → 一票否决（放弃或缓解后重评）；其余维度按矩阵加权。

## 3. 多视角评审（FULL 必做，LIGHT 简化为自检）

缺省 3 视角（复用 `../../best-practice-solution/SKILL.md` §2.2.4b 决策评审编排）：

| 视角 | 评审焦点 |
|------|----------|
| 架构/技术路线一致性 | 与单一信源/薄封装/松耦合架构原则一致性、与既有项目边界冲突 |
| 安全合规 | 敏感信息分级（铁律 #8）、授权边界（铁律 #7/7a）、移交前脱敏 |
| 成本+可演进性 | 独立后维护成本、回退路径（回收机制）、反信号观察期 |

**聚合决策（引用 MPV 决策矩阵，不另造三态）**：全部 SIGNED_OFF→SIGNED_OFF；1 视角 FAIL→CHANGES_REQUESTED；≥2 视角 FAIL 或任意 ERROR→BLOCKED；BLOCKED 未经人工确认禁止输出移交清单。

**真实外部信号（FULL 必备 ≥1）**：真实工具核验（如 `PROJECT_ROOT` 注入实测）/官方文档比对/先例项目实际引用计数；仅自评无外部信号视为评审未完成。

**评审模式声明**：本库语境下多视角评审为「多视角自评（非真实第三方）」，须在建议书评审区显式申明。

## 4. 决策记录草案

评审收敛后按 `../../best-practice-solution/SKILL.md` §3.5 格式输出（标识/决策/选项（含「维持现状」基线项）/理由/已验证/不确定/未关闭风险/反信号），交 `role-architecture` 正式化为 ADR。

**反信号必填**：独立化后调用率下降/无人维护 → 回收入本库；3 个月无实质演进 → 触发复评。

## 5. 产物

```markdown
## 孵化决策
- 决策：<移交独立项目 / 继续孵化 / 放弃>
- 依据：<五维矩阵结论> + <独立性判定结论>
## 评审报告
| 视角 | 结论 | 要点 |
## 聚合决策：<SIGNED_OFF / CHANGES_REQUESTED / BLOCKED>
## 决策记录草案（ADR-xxx 占位）
```

## 6. 门禁

- 决策非三选一明确结论 → 驳回
- FULL 档无真实外部信号 → 评审视为未完成
- BLOCKED 未经人工确认 → 禁止进入移交环节
- 收敛修订 ≤2 轮（CHANGES_REQUESTED 与 BLOCKED 均计轮），超限转人工确认
