# Stakeholder & Communications — 干系人沟通管理子技能

> 版本: v1.0 | 日期: 2026-09-07 | 对齐: PMBOK Stakeholder/Communications Management / Salience Model

## 定位

干系人映射、参与度评估与沟通计划管理。与现有能力互补：
- **RACI 矩阵** → `role-project-init`（已有，组织架构与责任分配）
- **干系人沟通** → `stakeholder-comms`（本子技能，权力-利益映射+沟通计划+参与度评估）

## 触发条件

用户说「干系人管理」「沟通计划」「干系人映射」「权力利益」「参与度评估」「沟通矩阵」「升级机制」「沟通频率」「沟通渠道」时加载。

## 权力-利益矩阵

```
         高权力
           |
  保持满意  |  重点管理
  (高权力   |  (高权力
   低利益)  |   高利益)
 ──────────┼──────────
  最少关注  |  保持知情
  (低权力   |  (低权力
   低利益)  |   高利益)
           |
         低权力
```

## 参与度评估（C/U/S/A 五级）

| 级别 | 含义 |
|------|------|
| C (Compliant) | 顺从——配合但无主动参与 |
| U (Unaware) |  unaware—— unaware of project |
| N (Neutral) | 中立——知情但不表态 |
| S (Supportive) | 支持——主动配合 |
| A (Leading) | 引领——推动项目成功 |

参与度差距 = 当前级别与期望级别的差距。差距 >= 2 级须制定沟通策略。

## 闭环执行系统

### 1. 任务入口
- 输入：用户要求管理干系人或制定沟通计划
- 前置：需确认项目干系人清单
- 不适用：RACI 责任分配（由 role-project-init 承接）

### 2. 验收门禁
- 必须产出：干系人映射表、沟通计划、参与度评估
- 通过条件：全部干系人映射到象限、沟通计划覆盖关键干系人
- 失败条件：关键干系人未映射、无沟通计划
