# model-selection — 模型选择技能

> **定位**：管理大模型提供商清单与定价，根据任务复杂度推荐最优模型。
> **职责边界**：只负责模型清单管理与选型建议，不处理路由/聚合/转发（由 free-api-hub 独立项目承载）。
> **触发词**：`模型选择`、`模型推荐`、`模型清单`、`模型定价`、`模型场景匹配`
> **Load when**：用户需要选择合适的大模型、查询模型定价、匹配任务与模型时。
> **技能版本**：v1.0.0

---

## 一、能力说明

### 1.1 模型清单管理

- **提供商覆盖**：42+ 模型，涵盖 7 大提供商
- **定价信息**：输入/输出 Token 价格、免费额度、折扣策略
- **能力矩阵**：上下文窗口、输出限制、工具支持、多模态能力

| 任务阶段 | 复杂度 | 推荐模型档位 | 成本档 |

## 二、使用方式

### 2.1 查询模型清单

```
用户：列出所有可用模型
→ 输出：已注册提供商模型清单与推荐场景.md 内容摘要
```

### 2.2 根据任务推荐模型

```
用户：我要做架构设计，推荐什么模型？
→ 输出：百炼 Qwen3.8-Max（S3 高危，¥2/M）
```

### 2.3 查询特定模型定价

```
用户：Qwen3.7-Plus 多少钱？
→ 输出：输入 ¥0.8/M，输出 ¥2/M，上下文 1M
```

### 2.4 任务结束时推荐模型（自动）

```
任务完成 → 调用 recommend_model(task_description) → 输出追加推荐行
```

输入：任务描述（当前任务的触发词+复杂度）
输出：`📦 推荐模型：[模型名]（[档位]，[成本]）`

判定规则：按 `references/model_selection.md` §4.2 路由决策表 + §5 输出规范

## 四、闭环执行系统

### 4.1 任务入口

- 用户触发词：`模型选择`/`模型推荐`/`模型清单`/`模型定价`
- 加载方式：`skill load model-selection`

### 4.2 执行状态

- [ ] 模型清单已更新
- [ ] 定价信息已验证
- [ ] 场景匹配已测试

### 4.3 验收门禁

- 模型清单覆盖 42+ 模型
- 定价信息与提供商官网一致
- 场景匹配准确率 ≥90%

### 4.4 失败处理

- 模型清单缺失：提示用户补充提供商信息
- 定价信息过期：提示用户更新定价
- 场景匹配失败：降级到人工推荐

### 4.5 产出与交接

- 产出：模型选型建议（Markdown）
- 交接：更新 `docs/已注册提供商模型清单与推荐场景.md`

### 4.6 审计记录

- 操作人：AI Agent
- 操作时间：ISO8601 格式
- 操作内容：模型查询/推荐/更新

## 闭环执行系统

### 1. 任务入口
- 输入：用户要求查询模型清单/推荐模型/对比定价/查询能力矩阵（`模型选择`/`模型推荐`/`模型清单`/`模型定价`/`模型场景匹配`）；
- 前置：已加载提供商清单与定价数据；
- 不适用：模型路由/聚合/转发（由 free-api-hub 独立项目承载）。

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|----------|
| 待启动 | 用户触发模型查询/推荐 | 确认查询范围 | 确定任务类型（S0~S3）与查询维度 |
| 执行中 | 查询范围确认 | 推荐结果生成 | 匹配提供商清单与定价，输出选型建议 |
| 校验中 | 推荐结果生成 | 门禁通过 | 校验推荐与任务类型匹配度 |
| 完成 | 门禁通过 | 进入交接 | 更新选型建议与交接断点 |
| 回退 | 清单数据过期/缺失 | 回到稳定版本 | 提示用户更新清单数据 |

### 3. 执行动作层
- 执行步骤 1：确定任务类型（S0~S3）与查询维度（定价/能力/场景适配）；
- 执行步骤 2：匹配提供商清单，输出模型选型建议（含跨场景适配方案）；
- 执行步骤 3：更新 `docs/已注册提供商模型清单与推荐场景.md`；
- 所需工具/脚本：`tools/check_skill_descriptions.py`、清单数据文件；
- 输入输出约束：输入为任务描述，输出为选型建议（Markdown）。

### 4. 验收门禁
- 必须产出物：模型选型建议（Markdown）；
- 门禁条件：推荐模型与任务类型匹配、定价数据为最新；
- 未通过处理：提示用户更新清单数据或调整任务类型。

### 5. 失败恢复
- 异常类型：清单数据过期/缺失；
- 恢复策略：提示用户运行清单更新流程或手动补充数据；
- 回退方式：保留上次有效推荐结果。

### 6. 交接审计
- 交接内容：当前清单版本、推荐结果、未关闭查询请求；
- 审计日志：操作人/时间/内容记录于 `13_安全审计台账.csv`。
