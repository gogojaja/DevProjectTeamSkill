# Portfolio Management — 项目组合管理子技能

> 版本: v1.0 | 日期: 2026-09-07 | 对齐: PMI PfM (Portfolio Management) / MoP (Management of Portfolios) / SAFe 6.0 LPM

## 定位

组织级项目投资决策能力——回答「做正确的事」。与现有技能互补：
- **单项目管理** → `role-project-mgmt`（把事做正确）
- **项目群协同** → `role-program-mgmt`（跨项目对齐）
- **组合投资** → `portfolio-mgmt`（本子技能，选正确的事做）
- **咨询诊断** → `role-mgmt-consulting`（成熟度评估/差距分析）

## 触发条件

用户说「组合管理」「项目选择」「投资评审」「战略评分」「组合优化」「Portfolio Review」「立项优先级」「淘汰项目」「组合平衡」时加载。

## 核心能力（6 个 action）

| action | 功能 | 台账 |
|--------|------|------|
| `register_portfolio` | 组合注册与分类（战略主题/投资类别/生命周期阶段） | 43_组合注册.csv |
| `score_strategic` | 5 维战略评分（对齐度/ROI/风险/资源可行性/紧迫度，加权总分） | 44_战略评分.csv |
| `analyze_balance` | 组合平衡分析（风险-收益分布、短中长期投资比、资源负载） | 44_战略评分.csv |

## 战略评分模型

5 维加权评分（总分 100）：

| 维度 | 默认权重 | 评分标准（1~5） |
|------|---------|----------------|
| 战略对齐度 | 30% | 1=无关 → 5=直接支撑核心战略 |
| ROI 预期 | 25% | 1=负收益 → 5=IRR>30% |
| 风险可控度 | 20% | 1=极高风险 → 5=几乎无风险 |
| 资源可行性 | 15% | 1=严重不足 → 5=完全具备 |
| 紧迫度 | 10% | 1=无时限 → 5=法规/合规强制 |

Go 阈值：加权总分 >= 3.5（满分 5）；低于 2.5 建议淘汰。

## Portfolio Review Board 决策规则

- **立项（Proceed）**：评分 >= 3.5 且资源可行
- **加速（Accelerate）**：评分 >= 4.0 且紧迫度高
- **暂停（Pause）**：评分 2.5~3.5 或资源冲突
- **终止（Terminate）**：评分 < 2.5 或战略不再对齐

决策铁律：Portfolio Review Board 做投资决策，PM 提供数据不决策，PMO 提供机制不决策。

## 闭环执行系统

### 1. 任务入口
- 输入：用户要求对项目组合进行注册/评分/优化/评审/价值跟踪
- 前置：需确认项目清单、战略主题定义、资源约束
- 不适用：单项目内部管理（由 role-project-mgmt 承接）

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 组合管理需求明确 | 确认项目清单与战略主题 | 读取现有台账 |
| 执行中 | 评分/分析/优化进行中 | 产出形成 | 按 action 流程执行 |
| 校验中 | 评审决策形成 | 用户确认 | 提交 PRB 决策 |
| 阻塞 | 缺战略主题/项目清单 | 补充信息 | 暂停并记录阻塞 |
| 完成 | 评审决策确认 | 台账更新 | 归档并通知 |

### 3. 验收门禁
- 必须产出：组合注册表、战略评分、优化建议、PRB 决策记录
- 通过条件：评分维度完整、决策经人工确认、台账更新
- 失败条件：评分维度缺失、未经确认即决策
