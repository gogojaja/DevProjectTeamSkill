# 自我診斷：PDCA 五步閉環 / 五層根因 / 哈希鏈防篡改 / 上下文健康

> 編排器：`../SKILL.md`

---

## 1. 定位

本域合併原 `shared/evolution.md`（SkillEvolutionSkill 技能自省）的**只讀診斷**能力與自我改進循環的**寫改**能力，形成完整閉環：

| 模式 | 能力 | 寫權限 | 產物 |
|------|------|--------|------|
| 只讀診斷 | PDCA 五步 / 五層根因 / 哈希鏈 / 健康監控 | 無（只讀） | 診斷報告、缺陷清單 |
| 寫改循環 | 偏差偵測 → 根因 → 提案 → 實驗 → 發布 | 有（經審批） | 改進落地、版本發布 |

> 原則：**先只讀診斷，後寫改落地**；診斷階段禁止直接改 SKILL.md。

---

## 2. PDCA 五步閉環診斷（evolve_start）

### 2.1 五步
| 步 | 動作 | 產物 |
|----|------|------|
| P1 | 收集信號（執行記錄/復盤/反饋/門禁報告） | 信號清單 |
| P2 | 對比預期 vs 實際，列出偏差 | 偏差清單（見 `deviation-detection.md`） |
| P3 | 根因分析（五層框架） | 根因鏈（見 `root-cause-analysis.md`） |
| P4 | 提議 P0-P2 分級改進 | 提案卡（見 `improvement-proposal.md`） |
| P5 | 實驗驗證 + 發布收斂 | 實驗報告 + 發布記錄 |

### 2.2 觸發
- 手動：用戶要求「自省」「診斷」「檢視技能庫」
- 自動（默認關閉）：預設自動條件滿足時觸發

### 2.3 限制
- 單次會話最多一輪診斷（禁止遞歸）；
- scope=full_system 且預算 >15K 時拆解或先確認；
- 診斷中禁止觸發業務技能。

## 3. 五層根因框架

| 層 | 名稱 | 問因方向 |
|----|------|----------|
| L1 | 角色層 | 操作者角色職責/行為是否錯位 |
| L2 | 流程層 | 流程步驟/檢查點/門禁是否缺失 |
| L3 | 規則層 | 規範/標準/約束是否缺失或衝突 |
| L4 | 上下文層 | 上下文丟失/壓縮/殘留導致遺漏 |
| L5 | 追溯性層（可選） | 決策/變更/版本是否可追溯 |

前四層必選，第五層可選；每層結論須附證據（證據編號）。

## 4. 哈希鏈防篡改（evolve_check_log）

### 4.1 機制
- `stored_hash` = SHA256(記錄內容 + prev_hash)
- 首條 = 創世基線（`genesis` 建立）
- 篡改 → 鏈斷裂 → `check` 定位首條斷點

### 4.2 存儲
| CSV | 內容 |
|-----|------|
| `Skill_Evolution_Log.csv` | 演進記錄（含哈希鏈） |
| `Skill_Lessons_Learned.csv` | 經驗教訓（含哈希鏈） |

### 4.3 觸發
- 懷疑篡改 / 定期校驗（月度）
- 快照與基線完整性校驗（配合 solidify 快照）

## 5. 上下文健康監控（ctx_health_check）

### 5.1 五項指標
| 指標 | 說明 |
|------|------|
| Token 佔用率 | 已用 / 上限 |
| 輪次 | 對話輪數 |
| 工具輸出累積 | 工具輸出量 |
| 技能負載 | 已載入角色包數 |
| 關鍵信息位置 | 關鍵內容在上下文中的位置深度 |

### 5.2 四級預警
| 級別 | 閾值 | 動作 |
|------|------|------|
| 綠 | 0-60% | 正常 |
| 黃 | 60-75% | 提示，考慮整理 |
| 橙 | 75-85% | 介入，壓縮瘦身（MicroCompact） |
| 紅 | 85%+ | 強制壓縮，先 solidify 固化 |

### 5.3 執行頻率
- 每輪對話後自包含執行；
- 階段切換前強制檢查；
- 紅區強制壓縮後**重讀 `references/iron_rules.md`** 作錨點。

---

## 6. 只讀安全鐵律

1. 診斷模式**只讀**：禁止改 SKILL.md、刪移文件；
2. 每條缺陷須附證據編號（`#` 引用）；
3. 提案 P0-P2 分級，不得無限擴散；
4. 寫改必須經審批後才動手（走 `improvement-proposal.md` 生命周期）；
5. 診斷中禁止觸發業務技能（只做技能庫自省）。

## 7. 與寫改循環銜接

```
ctx_health_check ──→ 診斷觸發
        │

        │

```
