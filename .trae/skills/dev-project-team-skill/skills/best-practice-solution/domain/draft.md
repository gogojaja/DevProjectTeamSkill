# Draft 方案草案（双栏模板）

> 归属：`../SKILL.md` §2.2.3　版本：v1.2.1

## 1. 目的
把调研与证据收敛为可直接交付的方案草案，对齐编排器 §2.2-1 双栏模板，并明确标注证据与不确定性。

## 2. 输出结构
```markdown
## 方案
### ✅ 可稳定达成效果
- <结论>「证据: EV-xxx [T1, 交叉验证2]」
- <可执行步骤 / 明确边界>
### ⚠️ 理论最优效果与当前限制
- <限制 / 不确定项>「证据: INSUFFICIENT」/「反信号: ...」
- <未验证假设清单>
```

## 3. 规则
1. **INSUFFICIENT 是第一类合法答案**：来源不足时直接说"不知道/缺证据"，不编造
2. 每条结论必须绑定证据卡 ID（EV-xxx）或显式 INSUFFICIENT；LIGHT 可用行内引用 `「来源: URL, T1, 日期」`
3. 草案末尾附升级提示：`如需第三方多视角评审/全量调研，回复「全量评审」`
4. LIGHT 草案单响应交付，不落中间文件、不铺开选项清单（决策记录草案标注"选项未铺开，仅含维持现状基线"）；FULL 草案可落工作目录供评审

## 4. 门禁
- 含无来源且无 INSUFFICIENT 标注的结论 → 不通过，回 Ground
- LIGHT/FULL 均须满足最小证据门槛（≥1 来源 或 显式 INSUFFICIENT）
