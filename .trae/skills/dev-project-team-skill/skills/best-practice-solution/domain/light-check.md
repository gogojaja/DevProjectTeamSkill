# Light-Check 轻量自检

> 归属：`../SKILL.md` §2.2.4a　版本：v1.2.1

## 1. 目的
为 LIGHT 档位提供最小质量门槛，防止"低风险快答"绕过证据要求直接答题。

## 2. 自检检查表（强制逐项）
| # | 检查项 | 判据 |
|---|--------|------|
| 1 | 结论有来源 | 每个设计结论 ≥1 个可展示来源或显式 INSUFFICIENT；`recalled_only`（本地命中）为合法状态 |
| 2 | 置信度已标 | 每条结论带 confidence（按 ground.md 映射表推导而非裸填） |
| 3 | 未展开评审 | 无来源锚定的结论不得展开评审，直接标不确定 |
| 4 | 反向信号 | 自问一遍"什么证据会推翻这个结论"，有则记录 |
| 5 | 黑名单复核 | 确认档位=LIGHT 未命中不可下调黑名单；**与用户主张冲突时取最严档** |

## 3. 产物
自检作为过程检查不单独输出大块，仅汇报未通过/异常项；结论并入 Draft 双栏草案，单响应交付。

## 4. 门禁
- 检查表 1~5 任一 FAIL → 升级为 FULL 或请求用户补充，禁止带病交付
- LIGHT 单响应交付，0 个中间文件；LIGHT-P0 0 网络调用；LIGHT 输出 token ≤2500（web 工具 context 单列封顶）
