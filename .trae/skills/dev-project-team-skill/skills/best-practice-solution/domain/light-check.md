# Light-Check 轻量自检

> 归属：`../SKILL.md` §2.2.4a　版本：v1.1.0

## 1. 目的
为 LIGHT 档位提供最小质量门槛，防止"低风险快答"绕过证据要求直接答题。

## 2. 自检检查表（强制逐项）
| # | 检查项 | 判据 |
|---|--------|------|
| 1 | 结论有来源 | 每个设计结论 ≥1 个可展示来源，或显式 INSUFFICIENT |
| 2 | 置信度已标 | 每条结论带 confidence（推导而非裸填） |
| 3 | 未展开评审 | 无来源锚定的结论不得展开评审，直接标不确定 |
| 4 | 反向信号 | 自问一遍"什么证据会推翻这个结论"，有则记录 |
| 5 | 黑名单复核 | 确认档位=LIGHT 未命中不可下调黑名单 |

## 3. 产物
```markdown
## LIGHT 自检结论
- 对照证据：<关键来源 + access_date>
- 反向信号：<可能推翻结论的未验证事项>
- INSUFFICIENT 项：<缺失证据清单>
```

## 4. 门禁
- 检查表 1~5 任一 FAIL → 升级为 FULL 或请求用户补充，禁止带病交付
- LIGHT 单响应交付，0 个中间文件，token ≤2500
