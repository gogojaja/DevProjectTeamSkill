# Research 调研（选项空间地图）

> 归属：`../SKILL.md` §2.2.2　版本：v1.1.0

## 1. 目的
广谱铺开选项空间，避免直接钻进单一方案；调研深度与档位挂钩，控制 token 与时效。

## 2. 档位化操作

### 2.1 LIGHT（缺省）
- 检索上限：≤1~2 次 `websearch` + ≤2 次 `webfetch`（单次 context ≤5000 字符）
- 只记影响取舍的 **top 3 结论 + 对应来源**（Pareto 截断，不穷举）
- 目标：首个可行候选即可，不追求完备

### 2.2 FULL
- 选项空间：铺开 2~5 个候选（超出合并描述或剔除被支配选项）
- 每候选记：适用场景 / 优点 / 缺点 / 已知取舍
- 每个将影响设计的结论在下游 `ground.md` 锚定来源

## 3. 检索操作约束
- 使用 `websearch`（广度检索，用于"有哪些选项"）与 `webfetch`（深度读单篇，用于"读来源"）
- **webfetch 安全约束**：仅公网 HTTPS 域名；禁 IP 字面量 URL、禁私有网段/`localhost`/内部域名/URL 内凭据
- 优先权威域：标准走机构域（IETF/RFC 走 rfc-editor 等）、官方文档走厂商官网

## 4. 产物
```markdown
## 选项空间地图
| 选项 | 适用场景 | 优点 | 缺点/取舍 |
|------|----------|------|-----------|
| A | ... | ... | ... |
```
- LIGHT 可精简为 top3 行；FULL 覆盖全部候选

## 5. 门禁
- 未锚定来源的结论不得参与设计（移交 ground.md 判定）
- 检索超限 → 截断并标注「未覆盖维度」，转接地中预算规则
