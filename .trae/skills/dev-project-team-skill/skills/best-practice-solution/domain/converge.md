# Converge 收敛决策

> 归属：`../SKILL.md` §2.2.5　版本：v1.2.0

## 1. 目的
吸收评审/自检意见，将方案修订至收敛，输出决策记录草案与未关闭风险，交接架构角色正式化为 ADR。

## 2. 修订循环
1. 汇总意见（LIGHT=自检结论；FULL=多视角评审 CR 清单）
2. 按裁决规则修订：
   - 证据加权（T1/T2 来源数）优先
   - 外部信号 > 内部自评
   - 驳回意见必须给理由；高严重度被驳回 → 强制升级人工确认（严重度判据见 review.md §3.4）
3. 重验并附「意见→处理结果」清单（CR-xxx → 采纳/驳回+理由，并回填 `status: new|ack|closed|deferred`）
4. 收敛轮次 ≤2（CHANGES_REQUESTED 与 BLOCKED 均计入）；超限转人工确认

## 3. 轮次预算保护例外
> 未关闭的高严重度发现**不受轮次预算保护**——必须转人工确认或在报告中显式标记为未关闭风险，禁止用"预算用尽"关闭评审结论。

## 4. 决策记录草案
```markdown
- **标识**：<ADR-xxx 占位，交架构角色正式编号>
- **决策**：<简短结论>
- **选项**：<被比较的 2~5 个选项；必须含"维持现状/不决策"基线项；LIGHT 可标注"选项未铺开">
- **理由**：<核心推理>（证据: EV-xxx）
- **已验证**：<实际核对过的>「来源+access_date」
- **不确定**：<未验证假设/INSUFFICIENT>
- **未关闭风险**：<高严重度未决项，须人工确认>
- **反信号**：<什么情况会推翻该决策>
```

## 5. 交接
- 决策记录草案 → `role-architecture` 正式化为 ADR（ADR-xxx 编号）并登记《需求-架构-代码追溯矩阵》
- FULL 评审报告按 MPV CSV 规范落盘（`评审报告_<对象>_<版本>_<…>.csv` 存项目根）
- 归档前跑 `desensitize.py` A/B 级扫描（内网 URL/IP/密钥三查）

## 6. 门禁
- 高严重度 CR 未处理/未升级人工 → 不得交付
- 决策记录缺「未关闭风险」「反信号」字段 → 不通过
