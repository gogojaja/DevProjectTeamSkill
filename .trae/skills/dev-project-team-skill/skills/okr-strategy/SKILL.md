# OKR & Strategic Alignment — OKR/KPI 战略对齐子技能

> 版本: v1.0 | 日期: 2026-09-07 | 对齐: Doerr OKR / Kaplan-Norton BSC / SAFe 6.0 Strategic Themes

## 定位

组织战略目标到项目的映射链——确保每个项目都对齐组织战略。与现有技能互补：
- **组合投资** → `portfolio-mgmt`（选正确的事）
- **战略对齐** → `okr-strategy`（本子技能，确保事做在正确方向上）
- **项目执行** → `role-project-mgmt` / `role-program-mgmt`（把事做正确）

## 触发条件

用户说「OKR」「目标与关键结果」「KPI」「战略对齐」「战略主题」「对齐度检查」「孤儿项目」「季度目标」「绩效指标」时加载。

## OKR 层级模型

```
组织级 Objective（定性、鼓舞人心）
  ├── Key Result 1（定量、可衡量）← 项目群 A 贡献
  ├── Key Result 2 ← 项目群 B + 项目 C 贡献
  └── Key Result 3 ← 项目 D 贡献

项目群 Key Results
  └── 项目 KPIs（可操作的领先/滞后指标）
```

## OKR 评分规则

| 评分区间 | 含义 |
|---------|------|
| 0.0~0.3 | 失败——需复盘根因 |
| 0.4~0.5 | 未达预期——需改进 |
| 0.6~0.7 | 理想区间——挑战性目标合理达成 |
| 0.8~0.9 | 目标可能不够挑战 |
| 1.0 | 过于保守——下季度需提高难度 |

## 对齐度审计规则

- **已对齐**：项目映射到至少 1 个战略主题，对齐度评分 >= 3
- **弱对齐**：映射到战略主题但评分 < 3
- **孤儿项目**：未映射到任何战略主题 → 预警

## 台账规范

- `台账/46_OKR登记.csv`：编号/层级(组织-项目群-项目)/Objective/Key Result 或 KPI/Owner/周期(季度)/目标值/实际值/完成%/评分/状态
- `台账/47_战略对齐矩阵.csv`：编号/项目名称/战略主题/对齐度评分(1-5)/映射日期/确认状态

## 闭环执行系统

### 1. 任务入口
- 输入：用户要求创建/更新/评分 OKR 或检查项目战略对齐度
- 前置：需确认战略主题定义、项目清单
- 不适用：组合投资决策（由 portfolio-mgmt 承接）

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | OKR/对齐需求明确 | 确认战略主题与项目清单 | 读取现有台账 |
| 执行中 | OKR 创建/更新/评分中 | 产出形成 | 按 action 执行 |
| 校验中 | 对齐审计完成 | 孤儿项目处理 | 预警 + 建议 |
| 完成 | 台账更新 | 归档 | 通知相关方 |

### 3. 验收门禁
- 必须产出：OKR 登记表、对齐矩阵、审计报告
- 通过条件：OKR 层级完整、对齐映射覆盖全部项目
- 失败条件：存在孤儿项目未处理、OKR 无 Owner
