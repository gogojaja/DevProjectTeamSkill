# 测试环境准备详细内容参考（Test Preparation Details）

> 本文件为 `test-preparation-skill` 测试依赖准备环节的详细内容参考，按需加载。
> SKILL.md 仅保留 Definition of Ready / Definition of Done / 规则，详细表格与本文件对应章节为准。

---

## 一、准备内容

| 准备项 | 内容 | 验收标准 |
|--------|------|---------|
| **测试环境** | 部署待测版本，配置数据库/中间件/依赖服务 | 环境可访问，服务正常启动 |
| **测试数据** | 准备测试账号、基础数据、业务数据 | 数据覆盖用例前置条件 |
| **第三方依赖** | 配置 Mock服务/沙箱环境/联调对接方 | 接口可正常调用 |
| **工具部署** | 部署测试工具（JMeter/Postman/OWASP ZAP等） | 工具可用，脚本可运行 |
| **CI流水线** | 配置自动化测试触发（如有接口自动化） | 代码提交可自动触发测试 |
| **环境配置管理** | 环境配置文件版本化、环境差异文档化 | 配置可追溯、可复现 |
| **冒烟验证** | 执行核心功能冒烟测试 | 核心功能可用，环境就绪 |

## 二、测试环境管理规范

| 管理维度 | 规范要求 | 说明 |
|---------|---------|------|
| **环境隔离** | 测试环境与开发/生产环境严格隔离 | 防止数据污染和相互影响 |
| **环境版本** | 每次部署记录版本号和部署时间 | 支持环境回退 |
| **配置管理** | 环境配置文件纳入版本控制 | 配置变更可追溯 |
| **数据快照** | 测试前创建数据快照 | 支持数据回退 |
| **环境监控** | 监控环境资源使用情况 | 及时发现环境异常 |
