# 测试用例设计详细内容参考（Test Design Details）

> 本文件为 `test-design-skill` 测试用例设计环节的详细内容参考，按需加载。
> SKILL.md 仅保留 Definition of Ready / Definition of Done / 规则，详细表格与本文件对应章节为准。

---

## 一、输出文档结构

标准化测试用例文档（Excel 格式）：
- 测试用例总览sheet（按模块统计）
- 功能测试用例sheet（完整步骤）
- 计算公式验证sheet（专项验证）
- 接口测试用例sheet（如有SIT/接口自动化）
- 非功能测试用例sheet（如有）
- 安全测试用例sheet（如有）
- 测试追溯矩阵sheet（需求→用例映射）

## 二、用例标准字段

| 字段 | 说明 |
|------|------|
| 用例编号 | 唯一标识，格式：TC-{模块缩写}-{序号} |
| 功能模块 | 对应需求文档中的功能模块 |
| 测试类型 | 功能/SIT/接口自动化/非功能/安全 |
| 用例类型 | 正向/逆向/边界/异常/计算 |
| 优先级 | P0(阻塞级)/P1(高)/P2(中)/P3(低) |
| 风险等级 | 极高/高/中/低（来自风险评估） |
| 测试项 | 具体测试点描述 |
| 前置条件 | 执行前需满足的条件 |
| 测试数据 | 执行用例所需的具体数据 |
| 测试步骤 | 编号步骤，含操作和数据 |
| 预期结果 | 期望的输出/状态/表现 |
| 对应需求 | 关联的需求字段或业务规则编号（RTM追溯） |
| 设计方法 | 等价类/边界值/决策表/场景法等 |

## 三、测试用例设计方法（参考 ISO 29119-4）

| 方法 | 原理 | 适用场景 | 关键要点 |
|------|------|---------|---------|
| **等价类划分** | 将输入划分为有效/无效等价类，每类取代表值 | 输入有明确有效/无效范围 | 有效+无效等价类各至少1个用例 |
| **边界值分析** | 在等价类边界及附近选数据 | 数值/日期/范围输入 | 上点（边界值）、离点（相邻值）、内点（典型值） |
| **决策表** | 系统化分析多条件组合 | 业务规则复杂的逻辑判断 | 列条件桩、动作桩，生成2^n组合再合并相似规则 |
| **状态迁移** | 测试系统状态变化有效性 | 有明确状态机的功能 | 四要素：状态、转换、事件、动作 |
| **正交实验法** | 用正交表减少组合爆炸 | 多参数多水平组合测试 | 用最少用例覆盖最多参数组合 |
| **场景法** | 模拟真实用户业务流程 | 业务流程清晰的系统 | 基本流（正常路径）+备选流（异常路径） |
| **错误推测法** | 基于经验预测易出错点 | 补充测试、历史缺陷高发区 | 必填不填、重复提交、极端值、特殊字符 |
| **因果图法** | 分析输入条件与输出结果的因果关系 | 输入条件间存在相互制约 | 转换为决策表后生成用例 |

**方法选择矩阵**：
- 明确输入范围 → 等价类 + 边界值
- 多条件组合 → 决策表 / 因果图
- 状态流转业务 → 状态迁移法
- 参数组合爆炸 → 正交实验法
- 用户业务流程 → 场景法
- 历史缺陷高发区 → 错误推测法
- 通常组合2-3种方法使用

## 四、用例分层建议（基于风险驱动）

| 用例层级 | 占比 | 优先级 | 覆盖目标 | 执行策略 |
|---------|:---:|:---:|---------|---------|
| 核心功能验证 | 40% | P0/P1 | 100%覆盖 | 每轮必执行 |
| 异常与边界场景 | 25% | P1/P2 | >=90%覆盖 | 每轮执行 |
| 接口与集成场景 | 15% | P1/P2 | 按接口清单覆盖 | 每轮执行 |
| 性能与安全场景 | 15% | P1/P2 | 按需求覆盖 | 专项执行 |
| 兼容性场景 | 5% | P2/P3 | 按环境清单覆盖 | 专项执行 |

## 五、用例评审检查清单

| 检查项 | 检查内容 | 通过标准 |
|--------|---------|---------|
| 需求覆盖 | 每条需求是否有对应用例 | 核心需求100%覆盖 |
| 用例独立性 | 每个用例可独立执行 | 无用例间执行依赖 |
| 步骤清晰性 | 步骤描述是否清晰可执行 | 无歧义、无遗漏 |
| 预期结果可验证 | 预期结果是否可观测可判定 | 有明确的验证点 |
| 数据完整性 | 测试数据是否已准备 | 数据覆盖前置条件 |
| 追溯完整性 | 用例是否关联需求编号 | RTM双向追溯完整 |
| 冗余检查 | 是否存在重复用例 | 无重复用例 |
