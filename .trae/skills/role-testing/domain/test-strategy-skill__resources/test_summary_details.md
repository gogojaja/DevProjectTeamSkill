# 测试总结与评审详细内容参考（Test Summary Details）

> 本文件为 `test-summary-skill` 测试总结与评审环节的详细内容参考，按需加载。
> SKILL.md 仅保留 Definition of Ready / Definition of Done / 规则，详细表格与本文件对应章节为准。

---

## 一、《测试总结报告》10 章

| 章节 | 内容 |
|------|------|
| 1. 测试概况 | 测试范围、测试类型、测试周期、参与人员 |
| 2. 用例执行统计 | 各类型用例数、执行率、通过率、失败率、阻塞率 |
| 3. 缺陷统计 | 缺陷总数、各严重程度分布、修复率、遗留缺陷清单 |
| 4. 缺陷度量 | DI值趋势、缺陷密度、逃逸率、重新打开率、平均修复时长 |
| 5. 测试覆盖分析 | 需求覆盖率、功能覆盖率、接口覆盖率、自动化覆盖率 |
| 6. 风险评估更新 | 测试后风险等级变化、残留风险评估 |
| 7. 遗留缺陷评估 | 每个遗留缺陷的风险评估与上线建议 |
| 8. 测试结论 | 是否满足准出标准、是否建议上线 |
| 9. 风险与建议 | 已知风险、改进建议、后续优化方向 |
| 10. 测试资产清单 | 用例/报告/缺陷/脚本/环境配置归档清单 |

## 二、测试阶段评审（stage_review）四大维度

| 维度 | 校验内容 |
|------|---------|
| 范围合规 | 测试范围是否覆盖全部需求功能点、RTM追溯是否完整 |
| 功能逻辑质量 | 严重/主要缺陷是否全部闭环、用例执行率是否达标、覆盖率是否达标 |
| 工程规范 | 测试用例/报告/缺陷记录是否完整规范、测试资产是否归档 |
| 风险安全 | 遗留缺陷风险评估是否充分、安全测试是否通过、残留风险是否可接受 |

## 三、测试门禁准出标准

| 门禁项 | 要求 | 说明 |
|--------|------|------|
| 严重缺陷闭环率 | 100% | 致命+严重缺陷全部关闭 |
| 主要缺陷闭环率 | >=90% | 重要缺陷基本闭环 |
| 一般缺陷处理率 | >=80% | 一般缺陷已处理或有明确计划 |
| 用例执行率 | 100% | 计划用例全部执行（含跳过/不适用） |
| 用例通过率 | >=95% | 已执行用例通过率 |
| 需求覆盖率 | 100% | 核心需求全部有对应用例并执行 |
| 安全测试 | 无高危漏洞 | 高危漏洞全部修复 |
| 性能测试 | 达标 | 核心指标满足需求阈值 |
| 测试报告评审 | 通过 | 报告经评审无异议 |
| RTM完整性 | 完整 | 需求→用例→缺陷双向追溯完整 |

## 四、测试报告评审检查清单

| 检查项 | 检查内容 | 通过标准 |
|--------|---------|---------|
| 数据完整性 | 执行数据、缺陷数据是否完整 | 无遗漏 |
| 指标准确性 | 度量指标计算是否正确 | 计算公式正确 |
| 覆盖分析 | 覆盖率分析是否真实 | RTM可验证 |
| 遗留缺陷评估 | 每个遗留缺陷是否有风险评估 | 100%评估 |
| 结论合理性 | 测试结论是否基于数据 | 有数据支撑 |
| 风险提示 | 已知风险是否充分提示 | 无遗漏 |
