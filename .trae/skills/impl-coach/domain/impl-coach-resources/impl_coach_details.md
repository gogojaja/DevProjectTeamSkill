## 1. 架构到代码翻译详细流程

### 1.1 翻译工作表

每次从架构到代码的翻译，需填写以下工作表：

| 步骤 | 输入 | 动作 | 输出 |
|------|------|------|------|
| 1. 读取架构 | C4 模型 / 架构图 | 识别容器、组件、依赖 | 容器清单 + 依赖矩阵 |
| 2. 映射目录 | 容器清单 | 每个容器 → 模块目录 | 目录结构草案 |
| 3. 映射接口 | 组件图 + 契约 | 每个组件 → 接口文件 | 接口定义文件列表 |
| 4. 映射实现 | 接口 + ADR | 选择模式 + 生成骨架 | 可编译的骨架代码 |
| 5. 验证方向 | 依赖矩阵 | 检查 import 方向 | 架构合规报告 |

### 1.2 依赖矩阵模板

| 调用方 ↓ \ 被调方 → | Presentation | Business | Data | External |
|---------------------|:-----------:|:--------:|:----:|:--------:|
| **Presentation** | - | ✅ | ❌ | ❌ |
| **Business** | ❌ | - | ✅ | ✅ |
| **Data** | ❌ | ❌ | - | ✅ |
| **External** | ❌ | ❌ | ❌ | - |

✅ = 允许依赖 ❌ = 禁止依赖

## 2. 模式选型详细决策表

### 2.1 创建型模式决策

| 场景特征 | 推荐模式 | 关键代码结构 | 复杂度 |
|---------|---------|-------------|--------|
| 对象创建需封装，子类决定具体类 | Factory Method | 抽象工厂 + 具体工厂 | 低 |
| 创建一系列相关对象族 | Abstract Factory | 工厂接口 + 产品族 | 中 |
| 对象构建步骤固定，参数多变 | Builder | Director + Builder | 中 |
| 全局唯一实例（配置、连接池） | Singleton | 私有构造 + 静态获取 | 低 |
| 需要复制已有对象 | Prototype | clone 方法 | 低 |

### 2.2 结构型模式决策

| 场景特征 | 推荐模式 | 关键代码结构 | 复杂度 |
|---------|---------|-------------|--------|
| 需要统一不同接口 | Adapter | 适配类包装被适配者 | 低 |
| 需要动态叠加功能 | Decorator | 包装类 + 委托 | 中 |
| 需要统一处理树形结构 | Composite | 组件接口 + 叶节点/容器 | 中 |
| 需要简化复杂子系统 | Facade | 门面类聚合子系统调用 | 低 |
| 需要共享细粒度对象 | Flyweight | 享元工厂 + 内部/外部状态 | 高 |

### 2.3 行为型模式决策

| 场景特征 | 推荐模式 | 关键代码结构 | 复杂度 |
|---------|---------|-------------|--------|
| 算法需运行时切换 | Strategy | 策略接口 + 具体策略 | 低 |
| 需链式处理请求 | Chain of Responsibility | 处理者链 | 中 |
| 需通知多个观察者 | Observer | 主题 + 观察者接口 | 中 |
| 需封装命令/操作 | Command | 命令接口 + 调用者 | 中 |
| 需管理状态转换 | State | 状态接口 + 上下文 | 中 |
| 需迭代聚合对象 | Iterator | 迭代器接口 | 低 |
| 需简化复杂 API | Template Method | 抽象基类 + 钩子方法 | 低 |

## 3. 多语言惯用法差异

### 3.1 接口定义惯用法

| 语言 | 接口方式 | 依赖注入方式 |
|------|---------|-------------|
| **Python** | `Protocol`（结构子类型）/ `ABC`（名义子类型） | 构造器注入 + `Depends()` |
| **TypeScript** | `interface` 关键字 | 构造器注入 + DI 容器 |
| **Go** | 隐式接口（duck typing） | 构造器注入（struct 字段） |
| **Java** | `interface` 关键字 | 构造器注入 + `@Autowired` |

### 3.2 错误处理惯用法

| 语言 | 异常处理 | 推荐模式 |
|------|---------|---------|
| **Python** | `try/except` + 自定义异常类 | 模块级异常 + 全局异常处理器 |
| **TypeScript** | `try/catch` + 自定义 Error | Result 类型（Either 模式） |
| **Go** | 多返回值 `(result, error)` | 错误包装 + sentinel errors |
| **Java** | `try/catch` + checked/unchecked | 全局 `@ControllerAdvice` |

### 3.3 异步编程惯用法

| 语言 | 异步模型 | 关键语法 |
|------|---------|---------|
| **Python** | `asyncio` + `async/await` | `async def` + `await` |
| **TypeScript** | `Promise` + `async/await` | `async` + `await` |
| **Go** | Goroutine + Channel | `go func()` + `chan` |
| **Java** | `CompletableFuture` / Virtual Threads | `.thenApply()` / `virtual` |
