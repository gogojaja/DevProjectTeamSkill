# environment_standard.md — 环境配置抽取标准（单源共享）

> 开发/测试/生产三套环境的统一配置标准。被 role-development / role-testing / role-deployment 引用。
> 配套台账：`台账/20_环境配置.csv`（dev/test/prod 三列并排）。
> 密钥一律存引用不存明文（详见 `security/secrets-example/.env.example` 与 `.gitignore`）。

## 1. 环境矩阵（dev / test / prod）

| 环境 | 用途 | 与生产关系 | 数据策略 | 边界 |
|------|------|-----------|----------|------|
| dev | 开发联调 | 结构一致、完全隔离 | 脱敏数据集 | 内网/本机，禁止生产数据 |
| test | 测试验证（SIT/自动化） | 与生产同拓扑、隔离 | 全量脱敏 + 造数 | 独立网络，禁止生产写权限 |
| prod | 生产运营 | 生产事实 | 真实数据 | 高风险，变更须 CAB/回滚预案 |

## 2. 配置项清单（N 类参考）

| 配置类 | 项 | dev | test | prod | 归属角色 |
|--------|----|----|----|----|----|
| 服务地址 | HOST / BASE_URL | | | | 按域 |
| 连接 | DB/缓存/消息 URL | | | | 开发/部署 |
| 版本 | 应用/依赖/中间件版本 | | | | 开发 |
| 开关 | 功能开关/Feature Flag | | | | 开发/测试 |
| 认证 | API Key 别名（非明文） | | | | 部署/测试 |
| 部署目标 | 集群/节点/命名空间 | | | | 部署 |
| 监控 | 监控/日志端点 | | | | 部署 |

> 表头建议列：`配置项 / 分类 / dev / test / prod / 归属角色 / 敏感标志(Y/N) / 密钥引用别名`。

## 3. 配置与检查规则

1. **密钥只存别名**（如 `DB_PASSWORD_ALIAS`），真实值经 `.secrets/`+凭据管理器/加密 `.env` 注入，禁止入库；
2. dev/test/prod 三环境运维参数（URL/版本/开关）统一写 `20_环境配置.csv`，供一键配置/检查/确认；
3. 环境变更走 `register_change` + `change_audit`；生产环境变更须 `CAB/ECAB`（见 role-deployment planning）；
4. 检查：`check_gate` 含「环境核对」——比对 `20_环境配置.csv` 与部署/测试实际配置，发现不一致即阻断；
5. 冒烟测试在对应环境通过后才允许进入正式执行/发布。

## 4. 常见入参

`env`：`dev` / `test` / `prod` 之一（默认 dev）。
