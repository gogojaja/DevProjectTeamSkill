# environment_standard.md — 环境配置抽取标准（单源共享）

> 开发/测试/生产环境的统一配置标准。被 role-development / role-testing / role-deployment 引用。
> **双套拓扑**：每项目采用「非生产组 dev+test 共享基础软硬件 + 生产组独立隔离」双套环境拓扑，详见 `environment_topology.md`（文件/端口隔离 + 共用边界 + RBAC）。
> 配套台账：`台账/20_环境配置.csv`（含环境组/隔离方式/端口区间/共用边界/权限角色列，dev/test/prod 配置并列）。
> 密钥一律存引用不存明文（详见 `security/secrets-example/.env.example` 与 `.gitignore`）。

## 1. 环境矩阵（双套环境组下的 dev / test / prod）

> 依据 `environment_topology.md`：dev+test 归属「非生产组」共用平台，prod 独立。下表为双套拓扑下的环境细节。

| 环境 | 环境组 | 用途 | 与生产关系 | 数据策略 | 边界 |
|------|--------|------|-----------|----------|------|
| dev | 非生产组 | 开发联调 | 结构一致、完全隔离 | 脱敏数据集 | 内网/本机，禁止生产数据 |
| test | 非生产组 | 测试验证（SIT/自动化） | 与生产同拓扑、隔离 | 全量脱敏 + 造数 | 独立网络，禁止生产写权限 |
| prod | 生产组 | 生产运营 | 生产事实 | 真实数据 | 高风险，变更须 CAB/回滚预案 |

## 3. 配置与检查规则

1. **密钥只存别名**（如 `DB_PASSWORD_ALIAS`），真实值经 `.secrets/`+凭据管理器/加密 `.env` 注入，禁止入库；
2. dev/test/prod 三环境运维参数（URL/版本/开关）统一写 `20_环境配置.csv`，供一键配置/检查/确认；**环境组（nonprod/prod）/端口区间/共用边界/权限角色在规划时一次性登记，后续只读引用**（`environment_topology.md`）；
3. 环境变更走 `register_change` + `change_audit`；生产环境变更须 `CAB/ECAB`（见 role-deployment planning）；
4. 检查：`check_gate` 含「环境核对」——比对 `20_环境配置.csv` 与部署/测试实际配置（含端口监听/数据目录/卷名），发现不一致即阻断；
5. 冒烟测试在对应环境通过后才允许进入正式执行/发布；
6. 端口与共享资源冲突经 CMDB `cmdb-cli.py` 仲裁（`25_环境资源清单.csv`，先注册先得，见 `multi_project_isolation.md` §10）。

## 4. 常见入参

`env`：`dev` / `test` / `prod` 之一（默认 dev）。
