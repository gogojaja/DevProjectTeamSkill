## 0. 铁律锚点（每轮回显三词）

```
铁律锚点：授权 → 备份 → 留痕
```

## 1. 系统/项目外文件铁律（最高优先，不可压缩忽略）

修改、删除**系统文件（%windir%\System32、hosts、注册表等）或项目外部文件（仓库之外路径，含其他项目目录）**必须三条件齐备，否则禁止执行：

1. **①先获用户明确授权**（`user_confirm=同意`）；
2. **②操作前强制备份**到项目内 `.backup/`（含时间戳）；
3. **③操作留痕**至 `13_安全审计台账.csv`。

> 必须经 `security_audit` 前置审计；未授权/未备份=违规高危操作，立即阻断。
> **操作前自问**：目标在仓库外吗？是系统路径吗？是其他项目目录吗？未授权则停，先问用户。

## 1a. 目录访问边界铁律（项目初始化强制）

- **默认边界**：本项目可读写/删除范围 = **本项目所在目录（含子目录）**，项目启动时经 `declare_access_boundary` 声明写入 `台账/26_访问边界.csv`（role-project-init）；
- **本项目目录之外的任何访问**（其他项目目录、系统文件、仓库外路径）一律经 `register_auth` 授权登记（`台账/14_授权登记.csv`），**未填有效期默认仅本次对话有效**，会话结束自动失效；跨会话须用户显式指定到期时间并留痕；
- 操作目标在本项目目录外 → 先查 `26_访问边界.csv` + `14_授权登记.csv`，无授权禁止读写/删除；授权未登记视为未授权。

## 2. 项目内文件保护

- 无用户明确指令**禁止删除/移动/重命名**项目内文件；
- 高危操作（改入口脚本/删移文件/配置变更）转发总控安全审计。

## 3. 敏感信息分级处理矩阵（统一管理）

敏感信息按「处置方式」分三级统一管理，**提交公共仓库前一律自问"这条数据属于哪级"**：

| 级别 | 保护对象 | 处置方式 | 代表场景 |
|------|---------|---------|---------|
| **A 级：禁止入库** | 密钥、凭据、Token、密码 | 仓库内只存别名/占位符，真实值经 `.secrets/` + 凭据管理器；历史泄露立即轮换 | 连接串密码、API Key、证书 |
| **B 级：脱敏入库** | 本机/环境专属信息（主机名/IP/用户名/绝对路径） | 提交前按 §3.1 强制脱敏后入库 | CMDB 快照、运维手册、连接串示例 |
| **C 级：可入库** | 脱敏后数据、非敏感配置、公共知识 | 正常提交 | 无真实值的模板、通用示例 |

### 3.1 B 级脱敏细则（提交公共仓库前强制）

**本机/环境专属信息（主机名、IP、用户名、环境路径等）在提交 GitHub 等公共仓库前必须脱敏**，否则禁止入库：

| 信息类型 | 脱敏规则 | 示例 |
|---------|---------|------|
| 主机名 | 可保留或匿名（按用户授权决定） | `Douglas` / `dev-host-01` |
| IP 地址 | **完全脱敏**或保留 C 段网段隐藏主机号（按用户授权决定） | `192.168.0.211` → `xxx.xxx.xxx.xxx` / `192.168.0.x` |
| 用户名 | 匿名化或保留（按用户授权决定） | `gogojaja` |
| 内网网段/域名 | 一律隐藏 | `10.x.x.x` → `xxx.xxx.xxx.xxx` |
| 环境变量路径 | 相对化或替换占位符 | `C:\Users\gogoj\...` → `%USERPROFILE%\...` |

**执行流程**：
1. 提交前识别文件中是否含本机/环境专属信息（主机名/IP/用户名/绝对路径）；
2. 按上表脱敏（**IP 完全脱敏为默认**，保留主机名须用户授权）；
3. 脱敏后复查全文确认无真实值残留；
4. 敏感度不确定时，先问用户授权再提交。

> 应用场景：CMDB 快照（`cmdb_export.csv`）、运维手册、连接串示例、日志、快照文件等一切会随仓库暴露的文件。
> 该脱敏不替代 A 级处理（§3），A 级真实值仍走 `.secrets/` + 凭据管理器。

## 4. 输出与格式

- 禁止产生 `.xlsx`（全库 CSV UTF-8 with BOM，token_standard §3）；
- 大输出转 CSV，仅回显首 5 行 + 行数。

## 5. 源码单源 / 不覆盖

- `.trae/skills/` 是唯一事实来源；deploy/solidify 不覆盖源码；shared 单源不手工复制。

## 6. 平台兼容铁律（双平台强制，不可压缩忽略）

本技能库所有启用项目**必须同时支持 Windows 与 macOS 双平台**：

1. **路径**：禁止硬编码单一平台绝对路径（`C:\...`、`D:\trae\...`、`/Users/...`、`/Volumes/...`）；脚本/配置统一用相对路径或平台自适应（Python `os.path`/`pathlib`、bash `$HOME`/`%USERPROFILE%`）；
2. **命令**：禁止依赖 Windows 专属命令（`py -3.11` 等）或 macOS 专属假设；Python 用 `sys.executable` 跨平台调用子脚本；
3. **行尾**：文本文件统一 LF（配 `.gitattributes`），防 Windows 检出 CRLF 导致反复 diff；
4. **文档**：涉及路径/命令时同时标注双平台写法（如 `~/.config/opencode/skills` vs `%USERPROFILE%\.config\opencode\skills`）。

> 细则见 `../references/token_standard.md` §6。
