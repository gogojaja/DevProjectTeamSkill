## 3. 任务 → 层映射（对齐 `model_selection.md` §4.2 + EV-2）

- **预算层**：commit message、lint/格式修正、文档字符串、批量重命名/格式化/简单替换（跨多文件）、首轮 triage。
- **中端层**：单文件 bug 修复、标准测试生成、常规 PR 评审、函数级重构、新代码文档生成。
- **旗舰层**：长程 multi-file 重构、端到端特性实现、架构/设计决策、安全敏感评审、跨全库推理、多 agent 协调。

## 4. 大批量任务推荐组合（预警「三选一 C」的依据）

- 批量文档/代码生成且低推理 → 本地 Qwen-Coder / DeepSeek / GLM-Flash（0 成本、隐私、可离线）；
- 超长大文档（>100K token）→ Gemini Pro/Flash（1M 上下文）；
- 架构 / 安全 / 跨库推理 → Opus / Sol / Gemini Pro（旗舰，质量优先）；
- 日常迭代 → Sonnet / Terra（中端）。
