## 2. 安全架构设计细节

### 3B.1 STRIDE 威胁建模

| 威胁类型 | 威胁描述 | 缓解措施 |
|----------|----------|----------|
| Spoofing | 身份伪装 | 强认证、TLS 双向身份、多因素 |
| Tampering | 数据篡改 | 完整性校验、签名、哈希 |
| Repudiation | 行为否认 | 审计日志、数字签名、时间戳 |
| Info Disclosure | 信息泄露 | 加密、最小权限、脱敏 |
| DoS | 拒绝服务 | 限流、熔断、高可用、防护 |
| Elevation | 权限提升 | 最小权限、RBAC/ABAC、安全边界 |

### 3B.2 认证授权

| 设计项 | 内容 |
|--------|------|
| 身份认证 | OAuth2/OpenID Connect/JWT/SAML/SSO |
| 权限模型 | RBAC（角色）/ABAC（属性）权限模型 |
| 会话管理 | 会话控制、过期、刷新 |
| 令牌管理 | 令牌签发/校验/吊销/密钥轮换 |

### 3B.3 数据安全

| 设计项 | 内容 |
|--------|------|
| 传输安全 | TLS(1.2+/1.3)、证书管理 |
| 存储安全 | 全盘/字段级加密、密钥管理（KMS） |
| 脱敏策略 | 字段脱敏、动态数据脱敏 |
| 数据防篡改 | 哈希链、签名、完整性校验 |

### 3B.4 审计链

| 设计项 | 内容 |
|--------|------|
| 操作日志 | 关键操作日志、留痕 |
| 安全审计 | 审计策略、日志留存（不先后写过） |
| 合规追溯 | 满足合规（等保/GDPR）审计要求 |

### 3B.5 纵深防御

| 设计项 | 内容 |
|--------|------|
| 网络层 | 防火墙、WAF、网络隔离 |
| 应用层 | 输入校验（SQL 注入/XSS）、安全编码、防绕过 |
| 数据层 | 数据加密、权限管控、审计 |
| 最小权限 | 服务账号最小权限、安全边界、凭证管理 |

### 3B.6 数据与安全设计的七原则检查

| 原则 | 检查项 | 检查结果 | 佐证 |
|------|--------|----------|------|
| 安全性 | STRIDE 全覆盖？策略、加密、审计齐备？ | ✅/❌ | 安全设计章节 |
| 成熟性 | 存储方案/加密方案有生产案例？ | ✅/❌ | 案例引用 |
| 稳定性 | 存储冗余/灾备设计？ | ✅/❌ | 存储策略 |
| 高效性 | 读写分离/缓存/存储性能达标？ | ✅/❌ | 数据存储 |
| 便捷性 | 数据字典齐全？数据可视化？ | ✅/❌ | 数据字典 |
| 跨平台性 | 标准协议/抽象平台差异？ | ✅/❌ | 数据流转 |
| 可移植性 | 数据可导出/迁移、备份恢复？ | ✅/❌ | 生命周期 |
