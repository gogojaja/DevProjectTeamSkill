> SKILL.md 仅保留环节骨架、DoR/DoD、规则与引用指针，详细表格以本文件对应章节为准。

## 环节 1：基线建立（Baseline Setup）

### 1.1 进度基准初始化

| 项目 | 内容 |
|------|------|
| 阶段划分 | 启动→需求→架构→开发→测试→投产→归档 |
| 里程碑 | 各阶段关键节点、验收点 |
| 任务拆解 | WBS 分解至可跟踪粒度 |
| 工期预估 | 每任务计划工期、资源分配 |

写入「进度基准」Sheet。

### 1.2 成本基准初始化

| 项目 | 内容 |
|------|------|
| 工时预估 | 每任务/每阶段计划工时 |
| 成本阈值 | 每阶段成本上限 |
| 超支标准 | 超出阈值百分比即判定超支 |

写入「成本基准」Sheet。

## 环节 2：里程碑与成本更新（update_milestone）

### 2.1 更新内容

| 更新项 | 写入位置 |
|--------|----------|
| 里程碑状态 | 「进度跟踪台账」Sheet |
| 完成率 | 「进度跟踪台账」Sheet |
| 实际工时 | 「成本消耗台账」Sheet |
| 实际成本 | 「成本消耗台账」Sheet |
| 资源投入 | 「成本消耗台账」Sheet |

### 2.2 触发时机

- 阶段验收通过后更新里程碑；
- 每次资源投入后记录工时/成本；
- 里程碑延期/超支时触发预警。

## 环节 3：门禁校验（check_gate 进度协同）

### 3.1 前置里程碑校验

| 检查项 | 内容 |
|--------|------|
| 前置里程碑 | 本阶段流转前的前置里程碑是否全部完成 |
| 拦截规则 | 前置里程碑未完成 → 禁止跳转下一阶段 |

### 3.2 风险预警

| 预警类型 | 触发条件 | 处理 |
|----------|----------|------|
| 进度滞后 | 任务滞后于计划 | 生成预警报告，输出调整方案 |
| 成本超支 | 成本超阈值 | 生成预警报告，输出调整方案 |

### 3.3 EVM 挣值分析（EVM 最佳实践）

| 指标 | 计算 | 判定 |
|------|------|------|
| 计划价值（PV） | 计划完成工作的预算 | 基准值 |
| 挣值（EV） | 实际完成工作的预算 | 实际值 |
| 实际成本（AC） | 实际发生的成本 | 实际值 |
| 进度绩效指数（SPI） | EV / PV | SPI >= 1 进度超前；SPI < 1 滞后 |
| 成本绩效指数（CPI） | EV / AC | CPI >= 1 成本节约；CPI < 1 超支 |
| 进度偏差（SV） | EV - PV | SV > 0 超前；SV < 0 滞后 |
| 成本偏差（CV） | EV - AC | CV > 0 节约；CV < 0 超支 |

写入「进度跟踪台账」「成本消耗台账」Sheet，用于周期复盘与风险预警。

## 环节 4：周期复盘（Periodic Review）

| 复盘类型 | 触发 | 内容 |
|----------|------|------|
| 阶段复盘 | 阶段切换 | 进度/成本偏差分析，输出调整方案 |
| 25/100 轮复盘 | 对话轮次 | 读取全量台账，输出完整进度、成本复盘报告 |
| 项目复盘 | 项目归档 | 全周期进度/成本分析，经验总结 |

### 刹车机制

连续 2 次延期/超支 → 停止 AI 自动调整计划，推送人工决策。
