# 安全审计详细内容参考（Project Security Audit Details）

> 本文件为 `project-security-audit-skill` 各环节**详细执行内容**的参考文档，按需加载。
> SKILL.md 仅保留环节骨架、DoR/DoD、规则与引用指针，详细表格以本文件对应章节为准。

---

## 环节 1：高危操作前置审计（Pre-audit）

### 1.1 高危操作范围

| 操作类型 | 示例 |
|----------|------|
| 入口脚本修改 | 修改入口/导入链路/目录 |
| 文件操作 | 删除、移动、重命名项目文件 |
| 配置变更 | 修改核心配置、权限 |
| 发布操作 | 部署、回滚、启停服务 |

### 1.2 操作影响评估表

| 字段 | 内容 |
|------|------|
| 操作 ID | 唯一审计编号 |
| 操作内容 | 具体操作描述 |
| 受影响组件 | 影响的服务/模块/文件 |
| 风险等级 | 高/中/低 |
| 回滚方案 | 操作失败时的恢复步骤 |
| 审批状态 | 待确认/已同意/已驳回 |

### 1.3 审批规则

- 高风险操作暂停，强制等 `user_confirm=同意`；
- 5 分钟无回复 → 自动驳回；
- 用户连续 2 次拒绝同一操作 → 永久终止。

## 环节 2：操作留痕（Audit Trail）

### 2.1 留痕铁律

| 规则 | 内容 |
|------|------|
| 全操作留痕 | 所有修改/调整/启停/回滚追加「安全审计台账」Sheet |
| 唯一操作 ID | 每次操作生成唯一 ID，永久追溯 |
| 不可删除 | 留痕记录不可删除、不可篡改 |
| 内容完整 | 操作时间/操作人/操作内容/影响组件/回滚方案/结果 |

### 2.2 写入内容

| 字段 | 内容 |
|------|------|
| 操作 ID | OP-YYYYMMDD-NNNN |
| 时间 | 操作时间 |
| 类型 | 修改/删除/移动/部署/回滚/启停 |
| 内容 | 操作详情 |
| 影响 | 受影响组件与风险 |
| 结果 | 成功/失败/回滚 |

## 环节 3：故障回滚（Rollback）

### 3.1 回滚优先逻辑

| 优先级 | 处理 |
|--------|------|
| 一键回滚 | 服务故障时自动调取备份，优先推送一键回滚 |
| 排查启动 | 仅 `user_confirm=查错` 时启动排查流程 |
| 完整根因 | 基础文件缺失/路径错误/语法报错类问题禁止判定为能力上限，必须完整根因修复 |

### 3.2 回滚步骤

| 步骤 | 内容 |
|------|------|
| ① 读取备份 | 调取最近可用备份 |
| ② 执行回滚 | 一键回滚至上一稳定版本 |
| ③ 留痕 | 回滚操作追加「安全审计台账」Sheet |
| ④ 验证 | 回滚后验证服务恢复 |
| ⑤ 根因分析 | 记录故障根因与改进项 |

## 环节 4：安全审计与变更协同

- 高危文件操作自动转发本技能审计（见 project-scope-change-skill 变更审计）；
- 安全审计结果纳入阶段门禁校验；
- 全项目归档时整合全部审计日志。
