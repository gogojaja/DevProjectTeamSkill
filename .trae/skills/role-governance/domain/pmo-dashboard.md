# PMO 运营仪表盘（E2 增强）

> 归属：role-governance 版本：v1.0.0
> 对齐：PMI PMO Practice · 治理三层模型（项目治理 < 项目群治理 < 组合治理）
> 工具支撑：`tools/pmo_dashboard.py` · MCP `pmo_dashboard`

## 1. 定位

PMO 运营仪表盘是 PMO 级综合视图，聚合跨项目数据形成一页纸仪表盘，支撑 PMO 日常运营监控与决策支持。

**与现有能力的关系**：
- **项目级** EVM（`role-governance` progress-cost）→ 仪表盘聚合多项目 SPI/CPI
- **项目群级** IMS（`role-program-mgmt`）→ 仪表盘聚合多项目群状态
- **组合级** 组合管理（`portfolio-mgmt`）→ 仪表盘提供运营视图

## 2. PMO 综合视图（一页纸）

| 维度 | 数据来源 | 聚合指标 |
|------|---------|---------|
| 进度健康度 | 30_项目群主进度 | 平均 SPI、SPI<0.8 项目数 |
| 成本健康度 | EVM 台账 | 平均 CPI、CPI<0.85 项目数 |
| 风险态势 | 12_风险问题台账 | P1/P2 风险总数、超 3 项 P1 的项目 |
| 资源负载 | 48_资源容量 | 平均利用率、过载(>85%)人数 |
| 组合状态 | 43_组合注册 | 活跃项目数、按类别分布 |
| 战略对齐 | 47_战略对齐矩阵 | 已对齐率、孤儿项目数 |

## 3. 预警规则引擎

| 预警规则 | 阈值 | 预警级别 |
|----------|------|---------|
| 进度严重滞后 | SPI < 0.8 | 🔴 红色 |
| 成本严重超支 | CPI < 0.85 | 🔴 红色 |
| 资源过载 | 利用率 > 85% | 🟡 黄色 |
| P1 风险集中 | 单项目 P1 风险 > 3 项 | 🔴 红色 |
| 战略脱对齐 | 孤儿项目（不对齐任何战略主题） | 🟡 黄色 |

## 4. 组合级风险聚合

- 汇总各项目 `12_风险问题台账.csv` 中 P1/P2 级风险；
- 按项目维度聚合，输出风险热力图数据（项目 × 风险等级矩阵）；
- 识别跨项目共性风险（同一风险出现在 3+ 项目中 → 系统性风险）。

## 5. 工具使用

```bash
# PMO 综合仪表盘
python3 tools/pmo_dashboard.py

# 输出包含：
# - 跨项目 SPI/CPI 健康度摘要
# - P1/P2 风险聚合
# - 资源负载摘要
# - 预警清单（按规则引擎）
```
