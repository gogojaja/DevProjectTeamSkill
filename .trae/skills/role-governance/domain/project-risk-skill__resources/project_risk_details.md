> SKILL.md 仅保留环节骨架、DoR/DoD、规则与引用指针，详细表格以本文件对应章节为准。

---

## 环节 1：风险登记册初始化（Risk Register Init）

### 1.1 初始风险预设

| 风险类别 | 示例风险 | 应对策略 |
|----------|----------|----------|
| 范围风险 | 需求蔓延、范围缩水 | 变更审批 + 范围冻结机制 |
| 进度风险 | 里程碑延期、任务滞后 | 进度预警 + EVM 监控 |
| 成本风险 | 成本超支、资源不足 | 成本阈值 + 超支预警 |
| 技术风险 | 技术选型失败、兼容性问题 | POC 验证 + 备选方案 |
| 质量风险 | 缺陷率高、覆盖率不足 | 质量门禁 + 缺陷闭环 |
| 安全风险 | 漏洞、数据泄露 | SAST/SCA 扫描 + 安全审计 |
| 人员风险 | 关键人员流失 | 知识交接 + 文档化 |

写入「风险&问题台账」Sheet。

## 环节 2：风险巡检（risk_scan）

### 2.1 巡检流程

| 步骤 | 内容 |
|------|------|
| ① 读取台账 | 读取「风险&问题台账」Sheet 全部风险 |
| ② 状态复核 | 复核各风险当前状态（新增/持续/缓解/已关闭） |
| ③ 新风险识别 | 结合当前进度/成本/质量/安全数据识别新风险 |
| ④ 评估更新 | 更新风险概率、影响、等级 |
| ⑤ 登记册更新 | 新增风险写入，关闭风险标记 |

### 2.2 风险等级评估

| 等级 | 概率×影响 | 处理 |
|------|-----------|------|
| 高 | 高概率×高影响 | 立即制定应对方案，上报决策 |
| 中 | 中概率×中影响 | 制定应对预案，持续监控 |
| 低 | 低概率×低影响 | 登记监测，定期复核 |

### 2.3 触发时机

- 定期巡检（每阶段切换、周期复盘）；
- 阶段切换时；
- 项目重大变更后。

---

## 环节 3：风险应对

| 应对策略 | 适用场景 |
|----------|----------|
| 规避 | 高风险且可避免 |
| 减轻 | 降低概率或影响 |
| 转移 | 可转移至第三方 |
| 接受 | 低风险且应对成本高 |
| 应急预案 | 高风险但不可控，预设触发条件 |

---

## 环节 4：风险与范围变更协同

- 需求变更 → 同步评估风险影响（见 project-scope-change-skill）；
- 架构变更 → 同步更新风险登记册（见 architecture-design-skill 协同）；
- 风险升级为重大问题 → 推送人工决策。
