# 项目治理详细内容参考（Project Governance Details）

> 本文件为 `project-governance-skill` 各环节**详细执行内容**的参考文档，按需加载。
> SKILL.md 仅保留环节骨架、DoR/DoD、规则与引用指针，详细表格以本文件对应章节为准。

## 环节 1：台账与项目基准初始化（Baseline Initialization）

### 1.1 create_baseline 执行细节

创建 `项目总台账.xlsx`（存放于 `.trae/` 目录），18 Sheet 页全量初始化：

| Sheet | 初始化内容 |
|-------|-----------|
| 启动组 | 项目编号、立项背景、目标、干系人清单、沟通记录 |
| 范围基准 | 范围边界、功能明细、禁止项、假设条件、制约因素 |
| 进度基准 | 阶段划分、里程碑、任务拆解、工期预估 |
| 成本基准 | 预算上限、成本阈值、超支判定标准 |
| 质量基准 | 分阶段质量验收标准、缺陷分级标准 |
| 范围变更台账 | 空表（首条变更追加写入） |
| 范围跟踪台账 | 空表（产出物基准清单首条写入） |
| 需求追溯矩阵 | 空表（需求分析阶段填充） |
| 进度跟踪台账 | 空表（里程碑更新时写入） |
| 成本消耗台账 | 空表（工时/成本消耗时写入） |
| 质量缺陷台账 | 空表（评审/缺陷发现时写入） |
| 风险&问题台账 | 初始风险登记册（预设常见风险 + 应对方案）+ 问题升级机制（P1~P4 分级/升级路径/响应时限/Owner/状态） |
| 组织架构 | 团队构成、角色职责、汇报关系、决策权限、RACI 矩阵（27_组织架构.csv） |
| 安全审计台账 | 空表（高危操作留痕时写入） |
| 门禁验收记录 | 空表（门禁校验时写入） |
| 执行记录 | 启动阶段执行记录 |
| 收尾归档 | 空表（归档时写入） |
| 开发追溯 | 空表（开发阶段填充） |

### 1.2 基线版本管理

- 台账基线版本号独立于技能版本与项目版本；
- 首次初始化记录为 `基线 v0.1`；
- 每次 `stage_close` 固化后递增基线版本号并自动备份 `项目总台账_v<版本>_backup.xlsx`。

## 环节 2：阶段基线固化（Stage Close）

### 2.1 stage_close 执行细节

| 步骤 | 内容 |
|------|------|
| ① 备份核心文件 | 备份本阶段产出物核心文件（含台账当前版本） |
| ② 更新基线版本号 | 台账版本号递增（v0.1 → v0.2 → ...） |
| ③ 记录验收结论 | 验收通过/有条件通过，条件项限期整改 |
| ④ 生成产出物基准清单 | 本阶段全部产出物（文件名/版本号/固化时间）追加写入「范围跟踪台账」Sheet，作为下阶段比对基准 |
| ⑤ 自动备份台账 | `项目总台账_v<版本>_backup.xlsx` |

### 2.2 固化前置检查

- [x] 本阶段评审通过（`stage_review`）
- [x] 本阶段门禁校验通过（`check_gate`）
- [x] 阻断级缺陷 0 遗留
- [x] 产出物清单完整无遗漏

## 环节 4：跨会话交接（Handover Export）

### 4.1 handover_export 执行细节

| 步骤 | 内容 |
|------|------|
| ① 拉取全套台账 | 读取全部 18 Sheet 当前数据 |
| ② 生成交接话术 | 新对话标准开场：项目目标/当前阶段/待办/关键台账路径 |
| ③ 打包台账快照 | 台账 Excel 快照（含版本号） |
| ④ 更新交接文档 | 更新 `跨会话交接文档.md`（项目目标/上下文摘要/待办/关键台账快照路径） |

### 4.2 强制归档（25/100 轮）

- **累计 25 轮对话（强制动作）**：复述项目总目标、汇总全部上下文、梳理已完成/待办任务，生成《对话归档总结》并**强制更新 `跨会话交接文档.md`**，确认归档完成后方可继续；
- **累计 100 轮对话**：输出完整需求/架构/测试/运维文档、复盘报告、跨会话交接话术；
- 未完成归档总结不得开始新会话。
