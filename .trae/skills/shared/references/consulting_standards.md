# 项目管理咨询标准（consulting_standards）

> 供 `role-mgmt-consulting` 使用的咨询行业最佳实践标准映射。本库为技能源码本体，不执行业务，本文件提供咨询方法论的参考锚点。

## 1. 咨询业务生命周期（Engagement 管理）

对齐 ICM（Institute of Consulting）与顶尖咨询机构（McKinsey/BCG/Bain）通用 Engagement 结构：

| 阶段 | 核心活动 | 常见产出 |
|------|---------|---------|
| 机会评估与投标 | 客户需求理解、机会筛选、竞标策略、赢率分析 | 商机评估、投标建议 |
| 建议书与合同 | SOW 界定（范围/交付物/里程碑/报价/风险/退出条款） | 建议书、SOW、合同 |
| 现状诊断 | 访谈、流程采集、数据复盘、对标 | 现状报告、痛点清单 |
| 成熟度评估 | 组织级项目管理成熟度评价 | 成熟度评估报告 |
| 方案设计 | To-Be 蓝图、方法论定制、PMO/治理/绩效设计 | PMO 蓝图、定制手册 |
| 实施与变革 | 变革管理、试点、推广、教练 | 变革计划、培训记录 |
| 成效评估 | 价值实现测量、结项评估 | 成效报告 |
| 知识资产化 | 案例库、模板、IP 沉淀 | 知识资产记录 |

## 2. 成熟度评估模型

- **P3M3**（Portfolio/Program/Project Maturity Model）：三层 × 5 级（初始/可重复/已定义/已管理/已优化）
- **CMMI v2**：能力成熟度模型，过程域与实践
- **OPM3**：组织级项目管理成熟度，含最佳实践库
- **Kerzner PMMM**：5 级项目管理成熟度模型（PM 培训需求驱动）

> 本库自建 5 维框架（治理/流程/组织/度量/工具）裁剪自上述模型，详见 `role-mgmt-consulting/domain/consulting-lifecycle__resources/maturity_model.md`。

## 3. 变革管理

- **Kotter 8 步**：营造紧迫感 → 组建指导联盟 → 创建愿景 → 沟通愿景 → 授权员工 → 创造短期速赢 → 巩固成果 → 文化固化
- **ADKAR**（Prosci）：Awareness（认知）→ Desire（意愿）→ Knowledge（知识）→ Ability（能力）→ Reinforcement（巩固）
- **干系人管理**：权力-利益矩阵、沟通计划、变更阻力识别

## 4. 标准体系映射

| 领域 | 参考标准 | 用途 |
|------|---------|------|
| 项目治理 | ISO 21500 / PMBOK 7th | 治理设计基准 |
| 项目群 | ISO 21503 / PMI SPM | 项目群治理设计 |
| 组合 | ISO 21504 | 组合治理边界 |
| 文档配置 | ISO 15489 / ISO 10007 | 受控库与配置管理 |
| 能力 | IPMA ICB4 | 组织能力模型 |
| 度量 | EVM / P3M3 | 绩效体系设计 |
| 环境资产 | CMDB（`tools/cmdb/`） | 工具选型与资产登记 |

## 5. 保密与边界（铁律锚点）

- 客户组织信息按 `references/iron_rules.md` §3 A/B 级处理：台账只存脱敏别名，真实信息走 `.secrets/`；
- 咨询只提供建议，不代行客户决策；落地执行由客户组织或本库执行角色承接；
- 访问客户方系统/信息经 `register_auth` 授权登记。
