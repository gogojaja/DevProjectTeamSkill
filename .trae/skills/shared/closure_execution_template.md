# 闭环执行系统（通用模板）

> 适用范围：所有新建/修改的 SKILL.md 维护产出。模板用于统一要求、便于门禁检查和后续复用。

## 1. 任务入口
- 输入：说明触发该技能的场景、任务目标和关键对象；
- 前置：说明必要条件、依赖文件、上下文、角色状态、用户确认；
- 不适用：说明在什么情况下不应该执行该技能，避免误触发。

## 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 任务已明确且前置条件满足 | 用户确认/系统启动 | 准备上下文与输入 |
| 执行中 | 任务已启动 | 关键动作完成或失败 | 按步骤执行 |
| 校验中 | 关键动作完成 | 通过/失败 | 检查门禁与中间产出 |
| 阻塞 | 依赖缺失/信息不足 | 补充信息/人工处理 | 暂停推进并记录原因 |
| 完成 | 验收通过 | 进入交接 | 归档证据与输出 |
| 回退 | 执行失败/门禁未过 | 回到最近稳定状态 | 回滚与复盘 |

## 3. 执行动作层
- 执行步骤 1：说明最前置动作；
- 执行步骤 2：说明核心执行动作；
- 执行步骤 3：说明验证与收口动作；
- 所需工具/脚本：列出所依赖的本地工具、脚本和标准；
- 输入输出约束：说明输入来源、输出落盘方式、文件路径或台账位置。

## 4. 验收门禁
- 必须产出物：列出必须生成的结果（文件、报告、台账、证据）；
- 通过条件：定义任务成功判定标准；
- 失败条件：定义未达标、需回退或需人工确认的情况；
- 审核对象：说明谁负责验收。

## 5. 失败处理
- 失败类型：例如缺失输入、环境问题、验证不通过、权限不足；
- 恢复策略：说明恢复动作和判断标准；
- 回滚方案：说明如何回退到最近稳定状态；
- 重试策略：说明重试条件与限制；
- 是否需要人工确认：说明高危/敏感场景是否需要人工确认。

## 6. 产出与交接
- 产出物列表：说明最终产出；
- 保存路径：说明落盘位置；
- 交接对象：说明下一节点接手对象；
- 下一步动作：说明下一个动作是什么；
- 归档条件：说明归档/固化时机。

## 7. 审计记录
- 执行时间：记录开始和结束时间；
- 关键参数：记录版本、模型、阶段、对象等关键信息；
- 关键决策：记录是否通过、是否回退、是否人工确认；
- 结果证据：说明证据路径和留痕方式；
- 失败原因：说明留痕位置。

## 8. 质量门禁（维护模式专用）
- 必须存在 `闭环执行系统` 标题；
- 必须包含状态机；
- 必须包含验收门禁；
- 必须包含失败恢复；
- 必须包含产出物和交接说明；
- 必须证明该技能可执行、可验证、可恢复与可交接。
