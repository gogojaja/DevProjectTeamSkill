- **变更记录**：v21.0.0 由 deployment-management-skill + 4 子技能重组为角色包

## 2. 触发规则

用户表达「投产策略/发布计划/发布准备/部署/发布监控/回滚/Go-Live/运维交接/DORA」时加载本包。先 Read 路由表，命中后只读对应 `domain/*.md`。

## 3. 流程（路由到 domain/）

| 环节 | action | 明细 |
|------|--------|------|
| 策略分析 | analyze_strategy | `domain/strategy.md`（决策树/风险矩阵/DORA/容灾） |
| 计划编写 | write_plan | `domain/planning.md`（12 章 + 变更分级审批） |
| 发布准备 | prepare_release | `domain/release.md`（六项准备 + 演练） |
| 发布执行 | execute_release | `domain/release.md`（金丝雀/蓝绿/滚动 + 三支柱监控） |
| 监控回滚 | monitor / rollback | `domain/release.md`（自动/手动回滚 + 数据还原） |
| Go-Live | go_live_review | `domain/handover.md`（六维门禁） |
| 交接 | handover_ops | `domain/handover.md`（Runbook/监控/on-call/SLA/发布总结） |

## 4. 发布铁律

任何发布前完成策略评审 + 变更分级审批；回滚预案必须随发布计划编写；实施按阶段灰度受控推进；DORA 指标基线评估。

## 5. 输出规范与边界

- 发布计划/总结/Go-Live 评审按 token_standard §3 输出 CSV；
- Go-Live 门禁经 `../shared/governance.md`；
- 边界：仅投产域；回滚数据还原遵循总控安全审计。

## 闭环执行系统

### 1. 任务入口
- 输入：用户要求制作发布计划、执行发布、监控变更、回滚或完成 Go-Live 交接；
- 前置：需具备已验证代码、环境配置、回滚预案和审批门禁；
- 不适用：未完成发布前置条件、缺少环境/回滚信息、或版本未达到准入条件时不应执行。

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 发布目标与版本已确认 | 发布计划开始 | 读取代码、环境、审批和风险 |
| 执行中 | 发布计划已发出 | 发布步骤/监控已开始 | 按灰度/分阶段推进 |
| 校验中 | 发布过程中关键指标已收集 | 监控满足要求或触发回滚 | 检查质量、风险和性能 |
| 阻塞 | 风险超阈值、环境异常、审批未通 | 补充信息/人工处理 | 暂停并生成回滚决策 |
| 完成 | Go-Live 评审通过 | 交接运营 | 生成发布总结和交接卡 |
| 回退 | 监控异常或重大事故 | 回到最近稳定状态 | 执行预案并保留审计 |

### 3. 执行动作层
- 执行步骤 1：确认发布策略、风险矩阵和审批条件；
- 执行步骤 2：准备发布演练、回滚预案和监控方案；
- 执行步骤 3：执行灰度/蓝绿/滚动发布、完成 Go-Live 门禁和运维交接；
- 所需工具/脚本：发布计划模板、回滚脚本、监控指标、总控门禁；
- 输入输出约束：必须形成发布记录、回滚准备和监控证据，不能在发布前跳过评审。

### 4. 验收门禁
- 必须产出物：发布计划、发布记录、回滚方案、Go-Live 评审、交接总结；
- 通过条件：发布前审批完成、监控正常、回滚预案可执行；
- 失败条件：监控超阈值、审批缺失、回滚方案不可用；
- 审核对象：部署负责人 + role-governance 总控 + 运维负责人。

### 5. 失败处理
- 失败类型：发布失败、性能异常、依赖错误、回滚失败；
- 恢复策略：按预案切回上版本并恢复稳定状态；
- 回滚方案：用版本回退、数据恢复和流量切换；
- 重试策略：修复根因后仅在允许条件下重试；
- 是否需要人工确认：回滚、重大变更和 Go-Live 放行必须人工确认。

### 6. 产出与交接
- 产出物列表：发布计划、监控记录、回滚证据、Go-Live 评审总结；
- 保存路径：部署目录、总控台账、交接文档；
- 交接对象：运维、项目负责人、总控；
- 下一步动作：继续运维监控或进入归档；
- 归档条件：Go-Live 通过、审计链完整并保存发布总结。

### 7. 审计记录
- 执行时间：发布开始/结束、回滚触发和交接时间；
- 关键参数：版本号、环境、灰度值、回滚策略；
- 关键决策：是否继续、是否回滚、是否放行；
- 结果证据：发布日志、监控图表、CSV 总结；
- 失败原因：写入总控审计台账和交接文档。
