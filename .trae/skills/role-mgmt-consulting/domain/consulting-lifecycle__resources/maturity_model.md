# 成熟度评估模型（maturity_model）

> 供 `assess_maturity` 使用的自建 5 维评估框架。对齐 P3M3 / CMMI / OPM3 裁剪，0~5 级评分，**证据必填**。

## 1. 评分等级定义

| 等级 | 名称 | 含义 |
|------|------|------|
| 0 | 未定义 | 无流程/无记录/无角色，凭经验行事 |
| 1 | 初始 | 有非正式实践，依赖个人，无文档 |
| 2 | 可重复 | 关键流程已文档化，可在相似项目重复，无统一标准 |
| 3 | 已定义 | 组织级标准流程，裁剪规则明确，全员遵循 |
| 4 | 已管理 | 流程量化管理，KPI/EVM 度量，偏差可控 |
| 5 | 已优化 | 持续改进闭环，根因分析，创新与优化制度化 |

## 2. 五维评估指标

### 2.1 治理 Governance（参考：OPM3 / ISO 21500 / 三层模型）
- 组合/项目群/项目三层治理是否齐备、权责是否清晰
- 决策门禁（立项/阶段/变更）是否制度化
- 干系人与升级机制是否明确
- 关键证据：章程/治理手册/决策记录/升级记录

### 2.2 流程 Processes（参考：CMMI / P3M3）
- 生命周期与阶段定义、活动裁剪规则
- 范围/进度/成本/质量/风险标准流程
- 变更控制与基线固化
- 关键证据：流程文档/模板库/裁剪记录/变更台账

### 2.3 组织 People（参考：IPMA ICB4）
- 角色定义与职责边界（PM/PMO/教练）
- 能力模型、培训计划、认证路径
- 激励与职业发展
- 关键证据：角色手册/能力矩阵/培训记录

### 2.4 度量 Metrics（参考：P3M3 / EVM）
- EVM 指标（CPI/SPI）、里程碑准点率、缺陷密度
- 报告节奏（周/月）与数据质量
- 度量驱动决策
- 关键证据：度量台账/报告/趋势分析

### 2.5 工具 Tools（参考：ISO 10007 / CMDB）
- PMIS/项目管理软件、配置管理（CMDB）
- 协作平台、自动化与集成
- 工具使用率与数据单一来源
- 关键证据：工具清单/使用日志/CMDB 登记

## 3. 评估与输出

- 评分：每维度 0~5，需填写支撑证据（访谈记录/文件/数据）；无证据不得给分；
- 差距：To-Be 目标级（客户期望）− As-Is 当前级（评估得分）= 差距；
- 优先级：按「差距 × 影响 × 可行性」排序；
- 输出：写 `36_成熟度基线.csv`（维度/评分/等级/证据/目标级/差距/优先级/建议）+ 文档版落 `咨询资产/`。

## 4. 对标参考

- P3M3：Portfolio/Program/Project 三层，5 级成熟度
- CMMI v2：能力成熟度模型（流程/工程/管理实践）
- OPM3：组织级项目管理成熟度，最佳实践库
- Kerzner PMMM：5 级项目管理成熟度模型
