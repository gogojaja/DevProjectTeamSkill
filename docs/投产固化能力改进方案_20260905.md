## 二、改进方案

### 2.1 G-01：MCP Server 固化门禁（高优先级）

**目标**：将 MCP Server 验证纳入 `solidify.py` 作为第 5 硬门禁。

**方案**：新建 `tools/check_mcp_server.py`，检查：
1. `skills_mcp_server.py` 语法编译通过（`py_compile`）
2. `@mcp.tool()` 装饰的函数数量 ≥ 预期下限（当前 10+ 工具）
3. 工具函数引用的核心脚本路径存在（`tools/*.py` 可达性）
4. `requirements.txt` 依赖声明完整

**集成点**：`solidify.py` 在 `[1d/5]` 之后增加 `[1e/5] MCP Server 门禁校验（硬门禁）`

**工作量**：~1 小时（新建工具 + 集成 + 测试）

### 2.2 G-02：插件链路验证（中优先级）

**目标**：固化时检查代理脚本的降级兜底能力。

**方案**：新建 `tools/check_plugin_chain.py`，检查：
1. 各 `_xxx_proxy.py` 语法编译通过
2. `plugin_registry.json` 格式有效
3. `.env.example` 存在且包含全部环境变量
4. 降级兜底函数 `_native_push_fallback` 可达（dry-run 模式验证）

**门禁级别**：**软门禁**（告警+报告，不阻断固化——插件为可选增强）

**集成点**：`solidify.py` 在 MCP Server 门禁后执行，输出插件链路健康报告

**工作量**：~1 小时

### 2.3 G-03：CI/CD 流水线（低优先级）

**目标**：push 时自动跑门禁，提前发现问题。

**方案**：新建 `.github/workflows/quality_gate.yml`：
- 触发条件：push to main / PR
- 步骤：checkout → Python setup → 跑 4 硬门禁（版本/闭环/发布级/废弃） → MCP Server 门禁 → 插件链路检查
- 不执行部署/发布（仅验证）

**工作量**：~1.5 小时

**注意**：当前单人主干开发，无 PR 流程，CI 价值有限。建议先实现门禁脚本（G-01/G-02），CI 流水线作为后续优化。

### 2.4 G-04：消费端验证 + 回滚（中优先级）

**目标**：发布后验证消费端加载 + 失败时回滚。

**方案 A（轻量，推荐）**：
- `publish_production.py` 末尾增加 `--verify` 选项：检查全局库中技能文件数量 ≥ 预期、SKILL_INDEX.md 存在
- 保留上一版本 `current` 软链指向，失败时手动 `ln -sf ../v<旧版本> current` 回滚

**方案 B（完整，后续优化）**：
- 发布后自动启动 MCP Server 冒烟测试（`--verify` 模式）
- 自动回滚：发布失败自动恢复旧 `current` 软链

**推荐**：先实施方案 A，方案 B 作为后续迭代。

**工作量**：方案 A ~0.5 小时，方案 B ~2 小时

## 三、实施优先级与分阶段计划

| 阶段 | 内容 | 工作量 | 依赖 |

| **Phase 1** | G-01 MCP Server 门禁 + G-02 插件链路验证 | ~2h | 无 |
| **Phase 2** | G-04 消费端验证 + 回滚（方案 A） | ~0.5h | Phase 1 |
| **Phase 3** | G-03 CI/CD 流水线 | ~1.5h | Phase 1+2 |

**总工作量**：~4 小时

## 四、验收标准

- [ ] `solidify.py` 执行时包含 MCP Server 门禁（硬门禁）
- [ ] `solidify.py` 执行时输出插件链路健康报告（软门禁）
- [ ] `publish_production.py --verify` 可验证消费端文件完整性
- [ ] CI 流水线 push 时自动跑门禁（Phase 3）
- [ ] 现有 4 硬门禁不受影响（回归验证）

## 五、风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|:----:|:----:|------|
| MCP Server 门禁误报阻断固化 | 低 | 高 | 先 dry-run 验证，调整阈值后再启用硬门禁 |
| 插件链路检查依赖本机环境 | 中 | 低 | 设为软门禁，仅告警不阻断 |
| CI 环境缺少 MCP 依赖 | 中 | 中 | CI 仅跑门禁检查，不启动 Server |
