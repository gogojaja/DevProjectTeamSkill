## 三、方案双栏

### ✅ 可稳定达成效果

**方案 A（推荐）：独立为 `dev-project-mgmt` 项目**
- 项目管理工具集：RAID 管理/进展报告生成/变更协调/EVM 计算
- 本仓库保留 `role-project-mgmt` 方法论技能 + 薄封装代理引用
- 证据：全量评估 94/100[high]、跨项目复用 20/20[high]

**技术架构**：
- 语言：Python 3.11+（跨平台）
- 数据：CSV（UTF-8 BOM）+ SQLite
- CLI 接口：`dev-project-mgmt raid/report/change/evm`
- 跨项目调用：`PROJECT_ROOT` 注入（对齐 tool_calling_standard.md）

### ⚠️ 限制

**方案 B：维持纯技能**：限制——无可执行工具，方法无法落地为自动化
