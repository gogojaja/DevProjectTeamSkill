## 三、方案双栏

### ✅ 可稳定达成效果

**方案 A（推荐）：独立为 `dev-test-tools` 项目**
- 测试工具集：跨项目测试执行/覆盖率聚合/缺陷台账/测试报告生成
- 本仓库保留 `role-testing` 方法论技能 + 薄封装代理引用
- 证据：全量评估 95/100[high]、跨项目复用 20/20[high]

**技术架构**：
- 语言：Python 3.11+（跨平台）
- 测试框架：pytest + coverage
- CLI 接口：`dev-test-tools run/coverage/report/defect`
- 跨项目调用：`PROJECT_ROOT` 注入（对齐 tool_calling_standard.md）
- 与 dev-task-scheduler 协同：夜间测试任务经调度器触发

### ⚠️ 限制

**方案 B：维持纯技能**：限制——无可执行测试工具链，跨项目测试能力无法统一
