## 三、方案双栏

### ✅ 可稳定达成效果

**方案 A（推荐）：独立为 `dev-security-tools` 项目**
- 安全审计工具集：审计台账工具/脱敏扫描/授权边界检查/密钥泄漏检测

- 证据：全量评估 96/100[high]、跨项目复用 20/20[high]

**技术架构**：
- 语言：Python 3.11+（跨平台）
- CLI 接口：`dev-security-tools audit/scan/boundary/secret-check`

- 审计四维：主机标识/客户端工具/模型名称/操作时间（对齐铁律 #7b）
