## 四、交互规则（铁律）

| 规则 | 内容 |
|------|------|
| **单一信源** | 每能力只在信源项目维护；消费方禁止内嵌实现副本 |
| **薄封装代理** | 消费方经 `tools/*_proxy.py` 转发，注入 `PROJECT_ROOT` 指向目标仓库 |
| **引用登记** | 消费方在 AGENTS.md/交接文档登记信源路径与授权编号 |
| **授权边界** | 跨项目访问经 `register_auth`（`14_授权登记.csv`），默认仅本次对话有效 |
| **调用方向** | 单向：业务层 → 技能库 → 基础设施；禁止反向依赖 |
