| 层 | 载体 | 归属 | 状态 |

| 三推实现（push 逻辑/熔断/真实 IP 回退） | dev-git-hub/tools/mirror_push.py（DEFAULT_REMOTES = ["origin","mirror","hub"]） | dev-git-hub ✅ | 已实现，hub 为单一信源 |

| 结论 | 三推**实现**完全在 dev-git-hub ✅；但触发机制当前失效 | | 需修复：钩子应由 dev-git-hub 版本控制 + 提供安装脚本 |
