## 四、决策记录草案

- **标识**：ADR-2026-09-01-001（待架构角色正式编号）
- **决策**：明确 free-api-hub 定位：清单管理 + 轻量网关，智能路由迁移到 dev-model-router
- **选项**：
  - A. **明确分工（本方案）** → ✅ 消除矛盾，职责清晰
  - B. 完全分离清单与网关 → ❌ 拆分成本高
  - C. 维持现状（矛盾共存） → ❌ 维护困难
- **理由**：EV-920~923（三重矛盾 + 功能重叠）
- **已验证**：交接文档/AGENTS.md/dev-platform-catalog（T1 本库实测）
- **不确定**：智能路由迁移工作量
- **未关闭风险**：迁移期间功能短暂不可用
- **反信号**：迁移后 dev-model-router 复杂度显著增加
