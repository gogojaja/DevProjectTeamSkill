## 三、模型选型（国内可用）

### 3.1 选型原则

1. **国内可访问**：必须在中国大陆可稳定访问
2. **能力匹配**：按任务复杂度选择合适模型
3. **成本可控**：优先免费/低价，必要时使用强模型
4. **稳定性**：API 可用性高，限流合理

### 3.2 推荐模型清单

| 模型 | 厂商 | 价格 | 能力 | 推荐场景 | 国内可用 |
|------|------|------|------|----------|----------|
| **Qwen-Max** | 阿里云 | ¥20/M input, ¥60/M output | 强推理 | 项目群规划、复杂架构 | ✅ |
| **Qwen-Plus** | 阿里云 | ¥4/M input, ¥12/M output | 中等推理 | 架构评审、需求分析 | ✅ |
| **Qwen-Turbo** | 阿里云 | ¥2/M input, ¥6/M output | 中等通用 | 文档编写、常规编码 | ✅ |
| **GLM-4** | 智谱 | ¥100/M input, ¥100/M output | 强通用 | 通用复杂任务 | ✅ |

### 3.3 模型路由策略

| 任务类型 | 推荐模型 | 成本档 |
|----------|----------|--------|
| S0 简单任务（重命名/格式化） | 本机 qwen2.5:7b | 免费 |
| S1 常规任务（文档/代码） | 本机 qwen2.5-coder:7b | 免费 |
| S2 复杂任务（架构/评审） | Qwen-Max / DeepSeek V3 | 低价 |
| S3 高危任务（安全/高危编码） | Qwen-Max | 强模型 |
| **项目群整体规划** | **Qwen-Max** | **强模型** |

## 四、风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 国内模型能力不足 | 复杂任务质量下降 | 混合策略：简单任务用本机，复杂任务用国内强模型 |
| API 限流/不稳定 | 任务执行中断 | 多提供商 fallback（free-api-hub 负责） |
| 成本超预算 | 财务压力 | 优先免费/低价，必要时才用强模型 |
| 数据合规风险 | 敏感数据泄露 | 敏感数据只用本机模型，不发送外部 |
