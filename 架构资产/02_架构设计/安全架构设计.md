# 安全架构设计

> 版本：v1.0.0　日期：2026-08-21　参考：OWASP ASVS · STRIDE · ISO/IEC 25010 安全性

---

## 1. 安全架构概述

### 1.1 设计原则

1. **最小权限**：任务执行权限最小化，仅授予必要的访问权限
2. **纵深防御**：多层安全防护，从网络、应用、数据多层次保障
3. **默认安全**：安全配置默认开启，而非可选
4. **审计可追溯**：所有操作留痕，支持安全审计
5. **失败安全**：安全检查失败时默认拒绝，而非放行

### 1.2 安全等级

本系统安全等级：**中等级别**

- 不处理 A 级敏感信息（密钥、凭据）
- 处理 B 级信息（路径、主机名等环境信息）需脱敏
- 主要风险：任务越权执行、恶意任务注入、数据泄露

## 2. STRIDE 威胁建模

### 2.1 威胁分析

| 威胁类型 | 威胁描述 | 风险等级 | 缓解措施 |
|---------|---------|---------|---------|
| **Spoofing 伪造** | 伪造任务身份执行未授权操作 | 中 | 任务注册校验、来源验证 |
| **Tampering 篡改** | 篡改任务定义、执行记录、状态数据 | 中 | 文件完整性校验、数据库事务 |
| **Repudiation 抵赖** | 无法证明操作是谁执行的 | 低 | 操作审计日志、执行节点记录 |
| **Information Disclosure 信息泄露** | 日志、执行记录泄露敏感信息 | 中 | 日志脱敏、敏感信息分级处理 |
| **Denial of Service 拒绝服务** | 恶意任务耗尽系统资源 | 中 | 超时控制、并发限制、资源隔离 |
| **Elevation of Privilege 权限提升** | 任务越权访问项目外资源 | 高 | 访问边界检查、沙箱执行 |

### 2.2 高风险项详细分析

#### EoP-001：任务越权访问外部资源

- **威胁**：任务脚本越权访问项目目录外的文件或系统资源
- **风险等级**：高
- **攻击路径**：恶意任务 → 读取/修改项目外文件 → 数据泄露或破坏
- **缓解措施**：
  1. 执行前检查访问边界（对照 `台账/26_访问边界.csv`）
  2. 任务运行在受限环境中
  3. 文件操作统一走封装的安全 API
  4. 敏感操作需审计留痕

#### DoS-001：恶意任务耗尽资源

- **威胁**：死循环任务或大量任务耗尽 CPU/内存
- **风险等级**：中
- **攻击路径**：提交恶意任务 → 无限循环 → 系统无响应
- **缓解措施**：
  1. 任务执行超时强制终止
  2. 最大并发数限制
  3. CPU/内存使用监控
  4. 任务队列堆积告警

#### ID-001：日志泄露敏感信息

- **威胁**：任务日志中包含路径、主机名等 B 级敏感信息
- **风险等级**：中
- **攻击路径**：日志输出 → 包含敏感路径 → 提交到公共仓库 → 信息泄露
- **缓解措施**：
  1. 日志脱敏扫描
  2. 敏感信息分级处理（B 级脱敏）
  3. 提交前安全扫描钩子

## 3. 访问控制

### 3.1 访问边界控制

严格遵循项目铁律 #7a：目录访问边界铁律。

- **默认范围**：仅允许访问项目所在目录
- **跨目录访问**：必须经 `register_auth` 授权，登记到 `台账/14_授权登记.csv`
- **检查时机**：任务执行前检查访问边界，越权则阻断执行

### 3.2 任务权限模型

| 权限级别 | 允许操作 | 适用任务 |
|---------|---------|---------|
| 只读 | 读取项目内文件、执行查询 | 巡检类、报告类任务 |
| 读写 | 读写项目内文件、执行修改 | 同步类、备份类任务 |
| 受限 | 仅允许在指定目录操作 | 临时文件清理任务 |
| 高权限 | 需额外授权，访问外部资源 | 需明确授权的特殊任务 |

### 3.3 权限检查流程

1. 任务注册时声明所需权限级别
2. 任务执行前校验权限
3. 文件操作统一走安全封装 API，API 内部校验权限
4. 越权操作记录到安全审计台账

## 4. 数据安全

### 4.1 敏感信息分级

遵循铁律 #8：敏感信息分级处理铁律。

| 级别 | 内容 | 处理方式 |
|------|------|---------|
| A 级 | 密钥、凭据、Token | 禁止入库，只存别名，真实值走 `.secrets/` + 凭据管理器 |
| B 级 | 主机名、IP、用户名、绝对路径 | 提交公共仓库前必须脱敏 |
| C 级 | 正常业务数据 | 正常入库 |

### 4.2 存储安全

- **SQLite 数据库**：存储在 `.secrets/` 目录，gitignore 不提交
- **CSV 台账**：B 级信息脱敏后写入，提交前经 desensitize 扫描
- **日志文件**：结构化日志，自动脱敏 B 级信息
- **配置文件**：敏感配置走 `.secrets/` 或环境变量

### 4.3 传输安全

- 本系统为本地单机运行，无网络传输
- 如接入外部告警渠道（邮件、飞书等），需使用 TLS 加密传输

## 5. 审计链

### 5.1 审计事件

| 事件类型 | 审计内容 | 存储位置 |
|---------|---------|---------|
| 任务注册 | 任务名称、创建者、时间、配置 | 执行记录 + 日志 |
| 任务修改 | 修改内容、修改者、时间 | 日志 |
| 任务删除 | 删除任务名、删除者、时间 | 日志 |
| 任务执行 | 执行时间、结果、耗时、错误 | CSV 执行记录 + SQLite |
| 越权尝试 | 任务名、尝试操作、目标路径 | 安全审计台账 |
| 告警触发 | 告警类型、任务名、时间 | 日志 |
| 调度器启停 | 启动/停止时间、版本 | 日志 + scheduler_state |

### 5.2 安全审计台账

文件：`台账/13_安全审计台账.csv`

新增记录类型：定时任务安全事件

| 字段 | 说明 |
|------|------|
| 事件编号 | SEC-YYYYMMDD-XXXX |
| 事件类型 | 越权尝试/任务注入/资源耗尽/其他 |
| 风险等级 | 高/中/低 |
| 任务名称 | 涉及的任务 |
| 操作描述 | 具体操作内容 |
| 处置结果 | 阻断/告警/放行 |
| 时间 | 事件发生时间 |
| 处理人 | 处理人员 |
| 备注 | 其他说明 |

## 6. 纵深防御体系

### 6.1 第一层：入口防护

- 任务注册校验：验证任务定义合法性
- 配置文件校验：YAML/JSON 格式校验，防止注入
- 来源验证：仅从指定路径加载任务

### 6.2 第二层：执行防护

- 访问边界检查：执行前检查权限
- 超时控制：防止无限循环
- 并发限制：防止资源耗尽
- 安全 API 封装：文件/网络操作统一走安全封装

### 6.3 第三层：数据防护

- 敏感信息脱敏：日志和记录自动脱敏
- 数据完整性：执行记录追加写入，不可篡改
- 存储隔离：敏感数据存 `.secrets/`，不提交 Git

### 6.4 第四层：检测防护

- 异常检测：任务执行时间异常、失败率异常告警
- 安全审计：越权操作记录、安全事件追踪
- 定期扫描：提交前自动扫描敏感信息

## 7. 任务沙箱设计（可选增强）

### 7.1 沙箱级别

| 级别 | 隔离方式 | 适用场景 |
|------|---------|---------|
| L1 无隔离 | 直接执行，仅权限检查 | 可信的内部任务 |
| L2 进程隔离 | 独立子进程执行 | 大多数任务（默认） |
| L3 容器隔离 | Docker 容器执行 | 不可信任务（暂不实现） |

### 7.2 L2 进程隔离

- 任务在独立子进程中执行
- 主进程监控子进程状态，超时强制 kill
- 通过标准输入输出传递数据，避免共享内存
- 子进程继承受限的环境变量
