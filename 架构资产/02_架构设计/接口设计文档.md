# 接口设计文档

> 版本：v1.0.0　日期：2026-08-21

---

## 1. 接口设计原则

1. **统一接口**：所有任务遵循统一的基类接口
2. **声明式配置**：通过装饰器或配置文件声明任务
3. **错误码规范**：统一的错误码和错误处理
4. **幂等友好**：接口设计支持幂等性实现
5. **向后兼容**：接口变更保持向后兼容

## 2. 任务接口

### 2.1 Task 基类

```python
class BaseTask:
    """任务基类，所有自定义任务继承此类"""

    # 任务元数据
    name: str                    # 任务名称（唯一标识）
    description: str             # 任务描述
    version: str = "1.0.0"       # 任务版本

    # 触发器配置
    trigger_type: str = "cron"   # cron / interval / date
    trigger_config: dict = {}    # 触发器配置

    # 执行配置
    max_retries: int = 3         # 最大重试次数
    timeout: int = 300           # 超时时间（秒）
    idempotency_key: str = None  # 幂等键表达式

    def execute(self, context: TaskContext) -> TaskResult:
        """
        任务执行入口
        Args:
            context: 任务执行上下文
        Returns:
            TaskResult: 执行结果
        """
        raise NotImplementedError

    def on_success(self, context: TaskContext, result: TaskResult):
        """执行成功回调"""
        pass

    def on_failure(self, context: TaskContext, error: Exception):
        """执行失败回调"""
        pass

    def on_retry(self, context: TaskContext, retry_count: int, error: Exception):
        """重试回调"""
        pass
```

### 2.2 TaskContext 执行上下文

```python
@dataclass
class TaskContext:
    """任务执行上下文"""
    task_name: str              # 任务名称
    run_id: str                 # 运行ID（UUID）
    scheduled_time: datetime    # 计划执行时间
    start_time: datetime        # 实际开始时间
    retry_count: int            # 重试次数
    idempotency_key: str        # 幂等键
    params: dict                # 任务参数
    logger: Logger              # 任务日志器
```

### 2.3 TaskResult 执行结果

```python
@dataclass
class TaskResult:
    """任务执行结果"""
    success: bool               # 是否成功
    message: str = ""           # 结果消息
    data: dict = field(default_factory=dict)  # 结果数据
    skip_retry: bool = False    # 是否跳过重试（业务错误不重试）
```

## 4. CLI 接口

### 4.1 命令清单

| 命令 | 说明 | 示例 |
|------|------|------|
| `scheduler start` | 启动调度器 | `python tools/scheduler/cli.py start` |
| `scheduler stop` | 停止调度器 | `python tools/scheduler/cli.py stop` |
| `scheduler status` | 查看调度器状态 | `python tools/scheduler/cli.py status` |
| `scheduler list` | 列出所有任务 | `python tools/scheduler/cli.py list` |
| `scheduler run <task_name>` | 手动触发任务 | `python tools/scheduler/cli.py run daily_backup` |
| `scheduler show <task_name>` | 查看任务详情 | `python tools/scheduler/cli.py show daily_backup` |
| `scheduler pause <task_name>` | 暂停任务 | `python tools/scheduler/cli.py pause daily_backup` |
| `scheduler resume <task_name>` | 恢复任务 | `python tools/scheduler/cli.py resume daily_backup` |
| `scheduler history` | 查看执行历史 | `python tools/scheduler/cli.py history --last 10` |
| `scheduler stats` | 查看统计信息 | `python tools/scheduler/cli.py stats` |
| `scheduler dlq` | 查看死信队列 | `python tools/scheduler/cli.py dlq` |
| `scheduler dlq-retry <id>` | 重试死信任务 | `python tools/scheduler/cli.py dlq-retry 123` |

### 4.2 输出格式

- 默认：人类可读的表格格式
- `--json`：JSON 格式，便于脚本调用
- `--csv`：CSV 格式，便于导入分析

```yaml
    type: threadpool

  default_max_retries: 3
  default_timeout: 300
  retry_base_delay: 60

  retry_jitter: 30

recording:
  enabled: true
  csv_path: 台账/31_定时任务执行记录.csv
  archive_days: 90

alerting:
  enabled: true
  system_notification: true
  failed_alert_threshold: 1
  queue_alert_threshold: 50
  heartbeat_timeout: 300

  include_paths:
    - tools/scheduler/tasks/
  config_files:
    - config/tasks.yaml
```

```yaml

  - name: daily_backup
```

## 6. 错误码规范

### 6.1 错误码格式

`SCH-XX-YYY`

- `SCH`：调度器模块前缀
- `XX`：错误分类（00-99）
- `YYY`：具体错误编号（000-999）

### 6.2 错误分类

| 分类码 | 分类名称 | 说明 |
|--------|---------|------|
| 00 | 成功 | 执行成功 |
| 01 | 配置错误 | 配置文件、参数错误 |
| 02 | 注册错误 | 任务注册、加载错误 |
| 03 | 调度错误 | 调度引擎错误 |
| 04 | 执行错误 | 任务执行错误 |
| 05 | 幂等错误 | 幂等校验错误 |
| 06 | 存储错误 | 数据库、文件存储错误 |
| 07 | 超时错误 | 执行超时 |
| 08 | 告警错误 | 告警通知错误 |
| 09 | 权限错误 | 权限、安全错误 |

### 6.3 常见错误码

| 错误码 | 说明 | 级别 |
|--------|------|------|
| SCH-00-000 | 执行成功 | - |
| SCH-01-001 | 配置文件不存在 | 错误 |
| SCH-01-002 | 配置格式错误 | 错误 |
| SCH-02-001 | 任务名称重复 | 错误 |
| SCH-02-002 | 任务类不存在 | 错误 |
| SCH-03-001 | 调度器启动失败 | 严重 |
| SCH-04-001 | 任务执行异常 | 错误 |
| SCH-05-001 | 幂等键冲突 | 警告 |
| SCH-06-001 | 数据库连接失败 | 严重 |
| SCH-07-001 | 任务执行超时 | 警告 |
| SCH-09-001 | 权限不足 | 错误 |

## 7. 版本管理

### 7.1 接口版本策略

- 遵循语义化版本（SemVer）：MAJOR.MINOR.PATCH
- MAJOR 版本：不兼容的 API 变更
- MINOR 版本：向下兼容的功能新增
- PATCH 版本：向下兼容的问题修复

### 7.2 兼容性保证

- 同一 MAJOR 版本内，接口向下兼容
- 废弃接口至少保留一个 MINOR 版本后移除
- 废弃接口添加 `@deprecated` 装饰器和文档说明
