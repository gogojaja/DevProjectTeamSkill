# ADR-007：多环境与 CI/CD 整体规划（外部方案）引用登记

## 状态

Accepted（已登记：外部业务方案引用，非本仓库架构决策）

## 上下文

外部评审通过的业务应用方案《多环境与 CI/CD 整体规划》v2.0 提交到本仓库归档。该方案自带 ADR-001~006（单机三环境/Compose/Drone/双模式/双仓库/.env），与本仓库既有架构决策库命名空间（ADR-001~006，scheduler 系）**完全冲突**。

## 决策

**登记为「外部方案引用」：ADR-007 作为命名空间分界声明。**

- 方案自带 ADR-001~006 归属**外部业务方案命名空间**（业务应用：单机三环境/Drone/双仓库），**不登记入本仓库架构决策库**
- 本仓库为技能库源码（AGENTS.md 定位），业务三环境方案仅作**架构策略留档**，不落地 Dev/Test/Prod
- 本仓库对方案仅采纳的**可移植思想**：CI/CD 自动化「提交即验证」闭环 + 配置/密钥分离 + 双仓库互备——落地载体为既有 GitHub Actions 质量门禁

## 理由

1. **命名空间隔离**：防外部方案 ADR 编号污染本仓库决策库（评审严重项已闭环）
2. **定位对齐**：方案面向业务应用部署，本仓库定位技能库源码维护，不落地业务三环境
3. **事实修正**（铁律「事实 > 文档」）：
   - 方案假设「本机 Windows 工作站 + 远端 Macmini」——实际**本机即 Mac mini**（Mac14,3），无独立远端
   - 方案选 Drone CI——本仓库已落地 GitHub Actions 质量门禁
   - 方案 ADR-005「Gitee 为主」——实际 origin=GitHub、mirror=Gitee

## 后果与缓解

- **后果**：方案与运行态差异归档时已标注；后续读方案须以本 ADR 为准
- **缓解**：归档文档头部含事实修正声明；评审报告标记复评 CHANGES_REQUESTED（整改后通过）
